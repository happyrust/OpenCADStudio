## 1. 现象与已确证的数据

**① 虚线节距比文件字面大约 1.7–1.8 倍**

- 文件：` Line2.sym` 发丝线经 `JStyleOverride`（覆盖 9，`+78`）指向 `0x002F` 图案 `-3.5, -1.75` mm；OCS 新鲜截图量到划 3.490 / 3.490 / 3.522 mm、空 1.745 mm，即 OCS 画的就是字面值。
- SmartPlant 参考图 `D:\work\cad\图片验证\pid-1.png`（x 2.117 px/mm）：三段划 12 / 13 / 14 px = 5.67 / 6.14 / 6.62 mm（均 6.14），两段空 6 px = 2.84 mm。放大约 1.75（划）/ 1.62（空），比约 2.16。
- **两种解释目前分不开**（都在 ±1 px 内）：(a) 单一比例 s ≈ 1.7 作用在 3.5 / 1.75 上；(b) SmartPlant 实际画的是一套英制图案 0.25″ / 0.125″ = 6.35 / 3.175 mm。
- 0201 上还有一组真正虚的笔画：`Electric` 电信号线（样式 79，`hop=Direct`，图案 `-1.905, -1.27` mm）。它是判别 (a)/(b) 的第二个样本：(a) 预期 3.3 / 2.2 mm（7.1 / 4.7 px），(b) 则另有数。**还没量。**

**② 线宽在屏幕上比 style 声明的粗**

- 参考图原始像素：主管线（橄榄）3 行（441–443）；设备表格线 1–2 行（样式宽 0.13 / 0.18 mm，按 1.997 px/mm 只有 0.26–0.36 px）；Manifold 红线 1 列；图框 1 行；Line2 发丝线（0.01 mm）2 行。
- 这些数还没有对到各自的 style 宽度上，也没算放大比例。「SmartPlant 对 style 声明的尺寸（线宽、点标记）全图放大」目前只是 #6 调查时的观感登记，10-09 那份七条差异清单在 docs 里没有正式记录。
- 可能的混杂因素：栅格化最小 1 px、抗锯齿、SmartPlant 的「线宽显示」选项（按实际 / 固定像素）。量的时候要分开记「纯色芯」与「浅边」。

**③ 二进制侧已知**（10-10 S2，`style.dll.i64`）

- 虚线消费点 `JStyleLinePointGen::IJStyleDashTypeClientImp` 槽 4（`sub_1003AAD0`）：每段先过单位换算 `sub_1007B150`，再乘画图上下文对象 `+24` 的 double——仅当该对象 `+8` 的 bit2（`& 4`）置位；否则乘 1。沿线铺开 `sub_1001A470` 同判据。
- 线宽笔画 `JStyleLineSolid` 槽 41（`sub_1003EF60`）**不读**这个 +24；点标记 `sub_1004A7B0` **读**。
- `sub_1004B460` 把同一个 +24 缓存进线样式 +184 并打脏标志。
- **谁写 +8 bit2 / +24、值从哪来，没追。** 这是本单 U2 的核心。
- `JSymbol::IJGraphicImp::Display`（`symbol.dex` `sub_100510E0`）另有一处：标志 `0x10000` 且比例 ≠ 1 时用显示上下文 +456 的 double 做 SF scale——与 +24 是不是同一个数，未知。

## 3. 要你拍板的（U4'，2026-10-11）

可证伪的一句：SmartPlant 把 style 里单位码为纸（11）的虚线段长、点标记尺寸和线宽，乘 `unitsCtx` 的纸因子 f0；f0 是视图「空间 2」矩阵把参考向量变完后的长度，再乘该空间单位栈顶（`render.dll` `sub_10061EE0` 的 `0x1006211F` / `0x10062133`，U7a §3–§4），这个数不在 `.pid` 里（U3：五图无字段落在 1.67±0.03）。本张参考图上这个积是 **1.67±0.03**（U1 §1：` Line2` 周期 8.79 mm / 5.25 mm = 1.675，`Electric` 周期 5.31 mm / 3.175 mm = 1.67）。文字字高不乘这个 1.67（U6 §1：拉丁大写 0.92–1.00）。`tagStyleOverride+24` 在 P&ID 链上是 1.0，不是这个倍数（U2 §4）。OCS 当前虚线、线宽、点标记、文字都按字面画。

这一句假在哪：第二张不同缩放的图上，虚线周期比若不等于该视图空间 2 的轴长×栈顶，机制被否；本图拉丁字高若测成约 1.67 倍文件字高，U6 被否；若 `.pid` 里找出一个 U3 漏掉的、渲染器实际读取的 1.67 字段，则「不在文件里」被否。

## 6. 风险、边界与开口

- **语料只有一张参考图**（0201），且非各向同性。单图上能定性、难定量到全局规则；0202（点划线 / 双点划线）的 SmartPlant 截图若日后拿到，优先补测。
- **(a) 与 (c) 的歧义**：3.5×1.75 ≈ 6.1 与 0.25″ = 6.35 只差 0.5 px。Electric 的 1.905/1.27 是唯一能当场判别的第二样本；若它也落在歧义带内，只能靠 U2 的二进制证据定。
- **线宽的栅格化下限**：0.13 mm 在 2 px/mm 下不到 1 px，屏幕上任何 1 px 线都说不出放大倍数；线宽的比例只能从 ≥0.35 mm 的线上读。
- **+24 可能根本不来自文件**：若是应用显示选项（SmartPlant「线宽显示」/「线型比例」），实作就只能是 OCS 侧可配置项，并且参考图当时的设置值未知——这一点要在判据里明写。这一条已关闭：U2 证明 P&ID 链上 `tagStyleOverride+24` 恒为 1.0；U7c 证明显示相关的应用设置 / 注册表键没有一条写进 `unitsCtx` 或渲染器配置。
- **共享 `target/`**：本单不构建；U3 只跑 `cargo run --example`，开跑前看一眼有没有别的会话在 build。

## 8.1 调查草稿

标题：`P&ID: SmartPlant scales paper-unit dash pitch and line width by the view paper factor; text is not scaled the same way`

> **现象** 参考图 `pid-1.png`（`DWG-0201GP06-01`）上，style 声明的虚线周期被放大 **1.67±0.03**：` Line2` 图案 3.5/1.75 mm（周期 5.25 mm）量到周期 8.79 mm；`Electric` 1.905/1.27 mm（周期 3.175 mm）量到周期 5.31 mm。0.70 mm 主管线约 1.80±0.08 倍，与 1.67 相容；更细的线落在 1 px 上下，说不出倍数。点标记约 1.54–1.75 倍。拉丁字高是文件字高的 0.92–1.00，**不是** 1.67。OCS 按字面画。
> **已排除** `tagStyleOverride+24` 不是这个倍数：P&ID 渲染链上它是 1.0（`pid-parse/docs/analysis/2026-10-11-dash-scale-writer.md`）。五张 `.pid` 里没有一个字段等于 1.67±0.03；虚线和线样式的单位码都是 11，比值不是 5/3。不是换成英制图案。不是 1.75，也不是固定 72/96/120 DPI。文字路径没有再乘 5/3 或 0.6。不是 SmartPlant 应用设置 / 注册表选项：显示相关键无一接到渲染配置（`pid-parse/docs/analysis/2026-10-11-display-option-strings.md`）。
> **机制** 纸单位（11）的虚线段、点标记和线宽乘 `unitsCtx` 的纸因子 f0。f0 是视图空间 2 的矩阵轴长乘单位栈顶（`render.dll` `sub_10061EE0`，`pid-parse/docs/analysis/2026-10-11-units-context-writer-render.md`）。这个函数里没有 5/3 常量，也没有 `GetDeviceCaps(LOGPIXELS)`。本图上 1.67 与 5/3、160/96、约 85–90 DPI、以及改正 6% 各向异性后 b≈0 的仿射是同一组像素，一张图分不开（`docs/evidence/2026-10-11-dash-pitch-mechanism-check/README.md`）。像素模式和 `ctx+128` 保持构造值 0 和 1.0：视图侧也没有人虚调写它们的槽（U7b）。这组值解释不了「虚线 1.67、文字≈1」，因为两者会共用 f0。1.67 不在仿射 a/b。
> **建议的实作（另开单，本 issue 先不改代码）** OpenCADStudio 加显示选项「纸单位样式尺寸的屏幕倍数」，默认 1，不写死 5/3。虚线、点标记、线宽乘它，文字不乘。不从 pid-parse 解一个不存在的文件字段。第二张不同缩放的 SmartPlant 截图（缩放离开当前这张，`Z>2.355` 或 `Z<1.897`）用来决定默认值能不能改成随视图缩放：量 ` Line2` 两个周期、`Electric` 一个周期加空段、一条 0.70 mm 线、一个拉丁字高。
