## 1. 目标

把本程序用的 `pid-parse`、`pid-plot` 从 10 月 25 日的版本换到主线的一个提交，改好用到它们的代码。两条硬规矩：

1. **读取和开图不变差。** 升级前后各走查三个样本包。图纸数不变，读不出、打不开的图不增加；每张图的数字有变化的，逐条写明原因。
2. **只换版本，不加功能。** 除了解析库本身带来的变化，本程序的行为不变。导出是 `SPEC-sppid-export.md` 的事。

## 3. 怎么升级

### 3.1 步骤

1. **前提。** 工作区干净：离线那批改动已提交。设计稿文件不算，它不动。
2. **升级前读数。** 在钉的版本上：门禁各跑一次；三个样本包各走查一遍；从全厂包挑 3 张图各出一份 PDF（§3.4）。报告全文存仓库外，读数记进 `readings.md`。
3. **换版本。** 改六处 `rev`。联网一次（`cargo fetch`）取新提交并更新 `Cargo.lock`。看 `git diff Cargo.lock`，对照 §2.4 的预期；出现预期之外的包变化就停下来报告。此后一律 `--offline --locked`。
4. **改到能编译。** `cargo check --offline --locked --lib` 的报错逐个改。记下改了几个文件、几处、各是什么变化。
5. **第一次汇报。** 汇报三件事：改了多少代码；锁文件实际变了哪些包；测试有多少条因升级失败、各属哪一类。（这就是地图 §5 说的「量完先报」；报完要不要等你发话，见 §9 第 4 问。）
6. **改到测试通过。** 规则见 §3.3。
7. **升级后读数。** 同第 2 步。用脚本逐张对比前后两份走查报告，写差异说明。
8. **判定（§3.2），提交，第二次汇报。** 地图 §5 说的另外两件事在这次汇报里答：开图的结果变了没有；`D03`、`D04` 读不读得出。

### 3.2 「不变差」怎么判

| 看什么 | 判定 |
|---|---|
| 列出的图纸数 | 三个包仍是 53、7、12 |
| 读不出图内对象的图 | 名单只能不变或变短（现在 2、1、11 张）。新冒出一张就是变差 |
| 打不开的图 | 名单只能不变或变短（现在 1、1、2 张）。新冒出一张就是变差 |
| 每张图的四个数：画出的图元、解出的记录、没画出的记录、图纸层 | 逐张对比。变了的每一张都写原因，指到 `pid-parse` 的提交或它的说明。没画出的记录变多，或者图元变少而说不出原因，就是变差 |
| 耗时 | 53 张全部导入的总时间不超过升级前读数的 1.5 倍。超过就报告，不自行放宽 |
| `PIDPLOT` | 现有测试通过；抽查的 3 张图升级前后都出得来 PDF，页数相同。字节不要求相同，文件大小的变化记下来 |
| 门禁 | 不退步（§5 第 6 条） |

变差了怎么办：先找原因。是本程序调用的方式要跟着改，就在这一块里改。是 `pid-parse` 的行为变了，就写清是哪个提交、影响哪几张图，停下来请你定：接受，还是到 `pid-parse` 那边修。不在本程序里绕过去。

### 3.3 测试的期望值变了怎么办

- 因为解析库的行为变化而失败的测试，可以改期望值。每一条都在提交说明和 `readings.md` 里写：哪条测试，原来的值，现在的值，原因。
- 说不出原因的不改，按变差处理。
- 不删测试，不加 `#[ignore]` 来躲。

### 3.4 `PIDPLOT` 抽查哪 3 张

全厂包里按 `.pid` 文件大小取最小、居中、最大的各一张。名单在第 2 步定下来，写进 `readings.md`，升级后用同样的 3 张。

## 7. 边界

共用约定 §8 之外，本块另有：

- **总是做**：六处 `rev` 一起改；升级前的读数留好再动 `Cargo.toml`；改期望值写原因。

## 11. 实现记录

实现时和上文有出入、或者上文没写到的地方，记在这里。

### `DEP-1` 对比脚本（2026-11-18）

- **输出是中文的 Markdown**，因为它要贴进 `readings.md`。报错也是中文，里面引用的报告标题保持原文。
- **退出码分三种**：0 没有变差；1 变差；2 参数或报告不能用（缺要读的一节，跳过了导入，各行加起来和合计行对不上，名单比标题说的短）。§4 只说了「非 0」。
- **算变差的多了一种**：两份报告的图纸数不同（对应 §3.2 第一行）。
- **用时不足 5 秒的不判**（`--time-floor-ms`，默认 5000）：两次里有一次全部导入用了 5 秒以上，才拿比值去比上限；否则比值只报不判。小包全部导入只要半秒多，这个量级的比值量到的是磁盘缓存，不是解析库。§3.2 的用时判定说的是 53 张的全厂包（三十几秒），它照常判。
- **四个数变了不算失败，但也不说「没有变差」**：图元变少、没画出的记录变多的图标出来，结论写成「说得出原因才算没有变差」。§3.2 的判定是「说不出原因就是变差」，原因脚本读不出来，要人写。
- **同名的两张图**按报告里的先后区分成 `名字`、`名字 [2]`。
- 读的是报告里这几处：`== drawings (N; M without a file) ==`；`== import of every drawing (…) ==` 一节的各行和合计行；末尾 `== N drawing(s) whose items did not read (…) ==` 和 `== N drawing(s) that did not import ==` 两份名单。走查改了这几处的写法，脚本会报格式不认识，届时两边一起改。

### `DEP-2` 升级前的读数（2026-11-18）

- **抽查的图是 4 张，不是 3 张。** §3.4 要按 `.pid` 大小取最小、居中、最大。最小的 `D03` 正是打不开的那张，出不了 PDF，升级前后的页数没法比。所以 `D03` 照样试并记下结果（升级后它能不能开，第二次汇报本来就要答），另加第二小的 `D04`。排序只算全厂包目录下 `backup-plant-data\` 里的 53 个 `.pid`，同一目录下 `验收数据\` 里的 5 个副本不算。
- **「用真实程序打开这张图，发 `PIDPLOT`」用的是不开窗口的方式**：`OpenCADStudio.exe --each <脚本> <图.pid>`。可执行程序、打开图纸和命令的处理都是同一套，只是没有窗口。出 PDF 读的是磁盘上的 `.pid`，不经过画布，有没有窗口不影响结果；不开窗口就不占桌面，升级后可以原样重跑。真实窗口里出图留给 `RD-4` 和 `ACC-1`。
- **程序用单独的 `APPDATA` 和 `TEMP`**（在证据目录里），不碰这台机器上的设置。图框模板因此从备份的压缩卷读进证据目录里自己的缓存，不用这台机器上已有的缓存；升级后换一个证据目录，条件相同。
- **页数用 PyMuPDF 读。** 出图程序把页对象收在对象流里，从字节里数不出页数。
- **另记了两项 §3.2 没要求的**：程序报的图元数和纸面大小；连出两次的 PDF 逐字节相同。前一项升级后一起比，后一项是 `SPEC-sppid-pdf.md` 拿字节相同作验收的前提。
- **可执行程序编在仓库的 `target\debug\`**（不入库）。这台机器上 cargo 把中间产物放在另一个目录，最终的程序放在这里；用之前看它的编成时间，确认是当次编的。

### `DEP-3` 换版本（2026-11-18）

### `DEP-4` 升级后的读数和判定（2026-11-18）

- **【文档】任务里改了一个源文件。** 清单说 `DEP-4` 只动 `readings.md`。升级后重出抽查图，3 张都没了图框；原因在本程序（下一条），按 §3.2「是本程序调用的方式要跟着改，就在这一块里改」在这一步修。改的只有 `src/io/pid_pdf.rs`，所以这次提交里有它，清单 §1 的门禁（库测试、两个 clippy、格式、分层检查）也照跑了。§5 第 9 条的文件名单因此再多这一项。
- **图框为什么没了。** 图纸所在的项目没有自带模板目录时，`PIDPLOT` 从备份的 `RefData~*.zip` 里把 `.igr` 模板读进临时目录下自己的缓存，再把缓存当作模板目录交给 `pid-plot`。写进缓存时，文件名前面加了名次（`1 CPE-SQ-A0.igr`、`2 A2-W - New.igr`），好让几个大小相同的模板按压缩卷里的先后被取到。旧版 `pid-plot` 只按大小挑模板，名字前面多一截不碍事。新版先看名字（`2b05914`、`1b5cce7`）：图纸里的图框链接写了哪个模板，就只用文件名以它开头的那些，再在里面按大小挑。比如链接写 `CPE-SQ~3.IGR`，取 `~` 前面的 `CPE-SQ`。加了名次的文件名没有一个对得上，点了名的图就一张都不带图框。
- **怎么改的。** 模板按压缩卷里的原名写进缓存。缓存目录的名字原来由压缩卷的路径、大小、修改时间算出，现在多算进一个布局号（`TEMPLATE_CACHE_LAYOUT`，这次是 2）。旧程序填过的目录里是带名次的文件；不换目录的话，新文件和旧文件混在一起，没点名模板的图会在里面按大小取到 `1 …` 那个。旧目录不删，它在临时目录下。
- **两条新测试，都先看到红。** `a_template_read_out_of_an_archive_keeps_its_own_name`：改之前失败，缓存里是 `1 CPE-SQ-A1.igr`、`2 A1-W - New.igr`。`the_cache_is_not_the_folder_an_earlier_layout_filled`：去掉算进布局号的那一行时失败。输出在证据目录的 `fix\red.log`、`fix\red2.log`、`fix\green.log`。
