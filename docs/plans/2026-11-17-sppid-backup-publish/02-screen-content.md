# 画面内容清单（给 Pencil 用）

> 状态：**待确认**（2026-11-18）。
> 用途：给画「备份数据包」这个画面的人看。写明每个区域代码能给出什么数据、有哪些状态、哪些东西给不出，免得画了代码做不到的东西。
> 分工（`00-capability-map.md` §8 第 5 问）：画框由你在 Pencil 里画；我不改设计稿文件。实现（`sppid-screen`、`sppid-export-ui`）等设计稿定稿后另写规格。
> 数据的出处：`SPEC-sppid-read.md`、`SPEC-sppid-export.md`；读数见 `01-shared-conventions.md` §3。

## 1. 导航

- 加一项「备份数据包」。建议的画面 id 是 `backup`：画面清单里现有的 id 都是一个英文词，如 `drawings`、`editor`。
- 放在哪一组由你定。建议挨着「图纸管理」，两者都是找图、开图的入口。
- 这个画面的数据来自本机的备份包，不来自协同服务器。没登录、没连服务器时照样可用。画面上不该出现项目、PBS、版本、签核这些项目库的东西。
- 加这一项时三处要一起改：设计稿的导航、画面清单 `screen-catalog.json`、代码里的画面名单。有一条测试核对这三处。清单的条目由我写，草稿在 §6。

## 2. 浏览画面的状态

五个状态，每个都要暗色和亮色。

| 状态 | 什么时候 | 画面上有什么 |
|---|---|---|
| 没打开 | 刚进这个画面，还没选备份包 | 两个入口：打开 zip、打开目录。一句说明这是什么 |
| 载入中 | 选了来源，正在还原、建索引 | 来源路径；「正在还原」；已用时间。**没有百分比**。全厂包第一次约 1 秒，解过的约 0.1 秒，所以这个状态多半一闪而过；大的 zip 第一次会久一些 |
| 已打开 | 索引建好 | §3 的各区域 |
| 图读不出 | 已打开状态下，选中的那张图读不出图内对象，或者文件缺失 | 图纸那一行有标记；详情区显示数据库里的字段（有的话）和一句原因；图内对象那一块显示原因，不是一张空表 |
| 出错 | 来源不存在、不是备份包、还原失败 | 一句错误（代码给的是一句话，没有错误码）；重新选择的入口 |

## 3. 「已打开」状态的各区域和数据

### 3.1 包的概要

| 数据 | 例（全厂包） | 一定有吗 |
|---|---|---|
| 工厂名 | `SQPlant` | 清单文件里有才有 |
| 软件版本 | `7.02` | 同上 |
| 备份类型 | `2` | 同上 |
| 备份时间 | `07/19/2026 20:13:24`，原样的字符串 | 同上 |
| 来源路径 | `D:\…\pid-test-data` | 有 |
| 来源方式 | 「直接使用目录（只读）」或「已还原到 某目录」 | 有 |
| 数量 | 53 张图，15 个包内文件，645 个参考数据文件，若干条警告 | 有 |

SQL Server 包没有可读的数据库，概要里只有清单文件的字段和数量。

### 3.2 装置组树

- 节点是装置组，可以嵌套。每个节点有名字和完整路径，如 `SQPlant / 00 / 00`。
- 每个节点能给出：直接属于它的图纸数，含下级的图纸总数。
- 两个特殊的组：包里有文件但数据库没登记的图（代码里叫 `Unregistered`），没有组的图（代码里叫 `(ungrouped)`）。界面上的中文叫法由你定。
- SQL Server 包读不到数据库，树退化成按文件夹分。

### 3.3 图纸清单

每张图能给出：

| 数据 | 说明 |
|---|---|
| 名字 | 数据库里的图名；没登记的用文件名 |
| 所在组 | 完整路径 |
| 文件在不在 | 数据库登记了但包里没有文件的，标「缺文件」，不能打开 |
| 数据库里的字段 | 图纸表这一行的全部列，若干对「列名：值」，空值也在。有哪些列由备份包决定，请按「有多少显示多少」画，不要假设固定的几列 |
| 图内对象读没读出 | 选中这张图之后才去读。53 张全读约 1.3 秒，可以在后台先读好。读不出时有一句原因 |
| 能不能打开 | 只有真去打开才知道。打不开时有一句原因。全厂包 53 张里有 1 张打不开 |

- 可以按名字搜索过滤。
- 量级：全厂包 53 张，小包 7 张。清单要能滚动。

### 3.4 图纸详情：属性

- 数据库里的字段，原样列出。
- 读出图内对象之后还有：图号（`DrawingNo`）、图名、图纸对象自己的若干对属性。

### 3.5 图纸详情：图内对象

- 每个对象有：编号（UID）；类型，英文原文，如 `Instrument`；发布类别，可能没有；若干对属性，每对有接口名、属性名、值。
- 按类型分组的数量可以现算。
- 量级：全厂包 53 张图共 14 894 个对象，平均每张约 280 个。清单要能滚动，要能按类型分组或过滤，不能假设一屏放得下。

### 3.6 其他

- **警告**：若干句话，比如清单里登记了但包里没有的文件。可能是 0 条。
- **还原缓存**：占用大小、所在目录；可以清除、换位置。这是经典面板已有的功能，新画面要不要放由你定。
- **库表、枚举映射、参考数据文件、图纸体检**：第一版不搬进新画面（地图 §8 第 2 问），留在经典面板。新画面可以放一个去经典面板的入口，也可以不放。

### 3.7 打开图纸

- 动作：双击或按钮。结果是编辑器画面多一个标签页，并切到编辑器。
- 打开要 0.1 到 6 秒（全厂包最慢的一张 6.2 秒）。要有「正在打开」的表示，没有百分比。
- 打不开：留在本画面，显示原因。
- 从编辑器回到本画面时，之前打开的包、选中的图还在。

## 4. 导出

### 4.1 入口

- 一个按钮「导出 publish 文件」，在包的概要旁边。名字不要叫「发布」，免得和平台自己的发布包混。
- 可用的条件：有打开的备份包，而且它有清单文件。只有散放图纸文件的目录不能导。不可用时要能看到原因。
- 一次导整包。不能勾选几张图。

### 4.2 对话框

| 项 | 说明 |
|---|---|
| 输出目录 | 必填。必须是不存在的或空的目录；选了非空目录要当场提示 |
| 工厂名 | 默认 `P01`，可改 |
| 参考目录 | 可选。给了就顺带和里面的参考文件比对 |
| 提示 | 包里有几个图纸文件；SQL Server 包加一句「这类包的导出没有验收过」 |

### 4.3 进行中

- 「正在导出」加已用时间（秒）。**没有百分比，没有「第几张」，不能取消。** 全厂包约 15 秒。
- 导出时可以继续用程序，比如切画面、看图。所以进行中的表示不该是挡住整个窗口的遮罩；回到本画面要还能看到它在跑。
- 同一时间只能有一次导出。正在导出时，导出按钮不可用。

### 4.4 结果

| 数据 | 例（全厂包） |
|---|---|
| 用时 | 15.2 秒 |
| 写出的图数、文件数 | 53 张，160 个文件 |
| 失败计数 | 0 |
| 图纸文件的交代 | 共 53 个：对上图纸 53，图框模板 0，没对上 0 |
| 没有 `DrawingNo` 的图 | 2 张，编号取自数据库 |
| 没写出的图 | 名单：图名加原因。可能 0 条，也可能几十条 |
| 写出了但带提醒的图 | 名单：图名加提醒。可能 0 条 |
| 整包层面的问题、提醒 | 若干句话。可能 0 条 |
| 比对结论，给了参考目录才有 | 53 张：7 张一致，0 张有差异，4 张的参考是另一版，42 张没有参考。另有逐张一句的明细，53 行 |
| 输出目录、清单文件 | 两个路径。可以放「打开目录」「打开清单」两个动作 |

结果有三种样子要画：

1. 全部写出，没有提醒。
2. 有没写出的图，或有提醒，或有比对结论：数字加名单。
3. 整次失败：一个错误码加一句话，没有任何数字。错误码有八种，见 `SPEC-sppid-export.md` §3.3。

## 5. 给不出的东西，请不要画

- 导出和载入的进度百分比、当前第几张、预计剩余时间、取消按钮。
- 导出时勾选图纸。
- 图纸的缩略图。开一张图要 0.1 到 6 秒，没法给清单里每张都画。
- 图纸的版本、状态、签核、负责人。那是项目库的东西。
- 导出历史。程序不记历次导出，只知道这次运行里的上一次。
- 备份包清单文件里的账号、口令。程序一律不显示。

## 8. 画的时候要你定的事

这几件不挡前三块的规格，画的时候定就行。

1. 导航里放在哪一组，叫什么（建议「备份数据包」）。
2. 两个特殊组的中文名（§3.2）。
3. 还原缓存的管理、去经典面板的入口，放不放（§3.6）。
4. 导出进行中的表示放在哪（§4.3）：本画面里一条，还是外壳上一个全局的提示。
