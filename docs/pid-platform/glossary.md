# P&ID 平台术语表

## 唯一词源声明

本术语表是本规范包全部交付物（PRD、架构文档、需求文档、界面原型、校验脚手架）的唯一词源。任何在上述交付物中出现的业务与技术术语，必须先在本表中登记后方可使用；当其他文档与本术语表对同一词汇的表述不一致时，以本术语表为准。`禁用别名`一列具有约束力：其中列出的叫法不得在任何交付物的标题、表格、界面标签或需求正文中出现。一个词能否登记为禁用别名，须按`禁用别名判定规则`中的四条标准逐条核验；经判定不构成别名的词汇记录在`已移除与不登记的疑似别名`中，不得重新加回别名列。

## 禁用别名判定规则

`禁用别名`一列由`scripts/pid-platform`下的术语校验测试机械执行：测试遍历`docs/pid-platform`目录下的全部`.md`文件，将每个已登记别名作为字面子串进行匹配，命中即判为违规。本表中别名列本身，以及`禁用别名判定规则`与`已移除与不登记的疑似别名`两节，因必须引用这些词而豁免扫描。一个词必须同时满足以下四条标准，方可登记为禁用别名。

**1.** **同一概念**。候选词必须是规范术语所指对象本身的错误叫法。若它指称的是另一个对象、另一层组合关系或另一套标准结构，则不是别名。三个判定性示例：阀体只是阀门的一个组成部件；WBS 与 PBS 是分属两套不同标准的分解结构；控制回路属于控制方案，而仪表回路是本平台对仪表对象的逻辑分组。

**2.** **非普通工程用词**。候选词不得是需求正文、验收标准或界面文案中无法回避的普通工程词汇。可判定方法：若不写该词就无法描述平台功能，则它不是别名。此类词包括：编号、接口、支管、接管、数据字段、基础数据、料表、物料表、配件、接头、主线。

**3.** **不另有所指**。候选词不得在参考产品手册或本项目引用的标准（HG/T 20519、SY/T 0003、DIN、ISO）中具有其他含义。可判定方法：在手册全文中检索该词，若出现其他义项即不得登记。已核实的两例：手册用线段描述管段在图面上的几何外观（"P&ID 上表现为一条线段"），又用主线指称图纸栅格（"栅格主线"）。

**4.** **可机械判定**。候选词必须是长度不少于两字的完整词形；不得是表中任一规范术语或受认可简称（`类库`、`TAG`、`BOM`）的子串，否则扫描会命中规范术语本身；任意两个已登记别名之间也不得互为子串。

登记时每一行须至少保留一个同时满足以上四条标准的别名；若某概念经核查确实没有错误叫法，该格填`—`，并在`已移除与不登记的疑似别名`一节记录理由。

## 术语表

下表登记本规范包的 24 个规范术语，中文名与英文名为正式称谓，定义描述其在本产品中的含义。

| 中文名 | 英文名 | 定义 | 禁用别名 |
| --- | --- | --- | --- |
| 位号 | Tag | P&ID 对象的身份主键，用于把图形、属性、拓扑关系、材料清单与 2D/3D 关联归属到同一个对象，而非仅供图面显示的文字。由项目位号规则生成并接受唯一校验。 | 标签号 |
| 管线 | Pipe Line | 共享同一管线号的一条或多条分支的总称，是工艺介质输送路径的顶层对象，承载管线号、介质、公称直径、管道等级等线级属性。 | 管道线 |
| 管路 | Pipe Run | 管线之下的一条分支，拥有自己的位号后缀与分支级属性，是管线在图面上实际走线与连接的组织单位。 | 子管线 |
| 管段 | Pipe Segment | 管件与管件之间、或管件与管口之间可连接的最小分段，其属性继承自所属管路。 | 管段线 |
| 管件 | Fitting | 接入管路的管道组成件，如法兰、盲板、异径管、过滤器，经连接点吸附在管段之间。 | 管配件 |
| 阀门 | Valve | 安装在管路上起通断、调节或保护作用的管件类符号实例，携带位号并参与材料统计。 | 阀件 |
| 设备 | Equipment | P&ID 中的工艺设备（容器、泵、换热器等），通过管口与管路连接，可在属性窗口中做 XY 方向比例缩放，同型实例之间可建立关联共享属性。 | 装备 |
| 管口 | Nozzle | 设备上供管路或仪表连接的开口，其位号前缀继承所属设备位号；可由项目设置中的自动管口功能生成。 | 接管口 |
| 仪表 | Instrument | 测量与控制类符号对象（如变送器、调节类仪表），可加入仪表回路，并经信号线与管口或设备建立关联。 | 仪表设备 |
| 仪表回路 | Instrument Loop | 一组协同完成同一测控功能的仪表构成的逻辑分组，支持新建回路、添加仪表、移除仪表三种维护操作。 | 仪表组 |
| 信号线 | Signal Line | 表示仪表之间、或仪表与设备之间信号传递路径的连线对象，经信号线型连接点挂接，可使用页间连接符跨图延续。 | 信号连线 |
| 页间连接符 | Inter-sheet Connector | 管线或信号线跨越两张图纸时的接续符号，携带属性传递与首尾（来去向）信息，把分布在不同图上的同一条线联为同一对象。 | 跨页符、跨页连接符 |
| 打断符 | Break Symbol | 管线交叉处表示视觉断开的标记符号，其样式与高度在项目设置中定义。 | 断开符、跳线 |
| 图例标准 | Symbol Standard | 一套完整命名的符号体系（手册列有 HG/T 20519、SY/T 0003、DIN、ISO），每个项目选定一套，一旦图面产生符号实例即不可切换。 | 图例集、符号标准集 |
| 符号 | Symbol | 图例标准之下可复用的图形定义，含名称、符号类型、颜色、状态与连接点，插入图纸后即成为携带属性的对象实例。 | 图符、图形记号 |
| 连接点 | Connection Point | 符号上用于吸附与建立拓扑连接的锚点，类型分为等径、异径、信号线，方向分为双向点、流入点、流出点。 | 挂点、连接锚点 |
| 类型库 | Type Library | P&ID 管理器下按业务对象组织的类/型树，子类型的类型编码全局唯一且创建后不可修改，类型节点上挂接属性分组与数据要素绑定，是全部对象属性 schema 的来源。 | 业务类库、类型表 |
| 数据要素 | Data Element | 平台层定义的可复用数据单元，绑定数据定义给出的类型与长度，被类型库中的属性分组通过"关联要素"引用。 | 数据元素 |
| 属性模板 | Attribute Template | 类型节点上预置的属性分组集合，约定关联要素、默认值、可选信息/必选信息级别与拼接规则，对象实例创建时按此落下属性。 | 属性分组模板 |
| 材料清单 | Bill of Materials (BOM) | 以位号为基准把图面对象实例按类型与属性聚合统计形成的交付清单，覆盖管件、阀门、设备等可统计对象；其模板结构与聚合口径由本规范包自行定义（新增设计）。 | 物料清单 |
| 设计规则检查 | Design Rule Check | 对图纸对象执行连通性、属性完整性与规则符合性检查的机制，含规则定义与结果模型；参考产品仅有一句宣称，具体设计由本规范包完成（新增设计）。 | 设计校核、错误校验 |
| 图纸版本快照 | Sheet Version Snapshot | 单张图纸在某一时刻的图形内容与对象数据的整体存档，可生成多个版本并做两两差异比对。 | 版本存档、快照版本 |
| PBS | Plant Breakdown Structure | 项目内组织 P&ID 图纸的层级分解结构（按装置、单元等逐级展开），图纸挂接在 PBS 节点下，权限圈选与发布范围沿其组织。 | 工厂分解树 |
| 项目主数据 | Project Master Data | 项目级共享的取值数据集合，包括公称直径序列、管道等级、绝热等级、流体介质等，绘图时作为对象属性的取值来源。 | 主数据表 |

## 已移除与不登记的疑似别名

以下词汇曾在术语评审中被考虑登记为禁用别名，经对照`禁用别名判定规则`逐条核验后被判定不构成别名，或虽曾登记而在本次修订中移除。后续维护者不得将这些词重新加回别名列；如确需登记，须先以反证推翻上述判定标准中的相应条款，而非绕过该标准。

| 词 | 曾被归到 | 理由 |
| --- | --- | --- |
| 阀体 | 阀门 | 阀体只是阀门的一个组成部件，与阀门指称的不是同一对象，把部件名当作整机的错误叫法会误伤合法表述，违反第 1 条（同一概念）。 |
| WBS | PBS | WBS（工作分解结构）与 PBS（装置分解结构）分属两套不同标准体系，指称不同的分解结构而非同一对象，违反第 1 条（同一概念）。 |
| 控制回路 | 仪表回路 | 控制回路属于控制方案层面的对象，仪表回路是本平台对仪表对象的逻辑分组，二者指称不同事物，违反第 1 条（同一概念）。 |
| 线段 | 管段 | 参考产品手册用线段描述管段在图面上的几何外观（"P&ID 上表现为一条线段"），该词已另有所指，违反第 3 条（不另有所指）。 |
| 编号 | 位号 | 编号是通用计数用词，手册中存在图纸编号、工作区编号、记录编号、主项编号、起始编号等大量用法，需求行文无法回避，违反第 2 条（非普通工程用词）。 |
| 数据字段 | 数据要素 | 手册将数据要素界定为"管理业务中的数据字段或属性"，描述该概念时无法回避此词，违反第 2 条（非普通工程用词）与第 3 条（不另有所指）。 |
| 基础数据 | 项目主数据 | 基础数据是项目初始化与导入语境中对前期参考数据的泛称，与项目主数据不是同一概念且属普通工程用词，违反第 1 条（同一概念）与第 2 条（非普通工程用词）。 |
| 料表 | 材料清单 | 料表是材料表的口语化简称，工程用法中可指任何材料类表格，包括图纸上的图例表格，属普通工程用词且另有所指，违反第 2 条与第 3 条。 |
| 物料表 | 材料清单 | 物料表同样是材料类表格的泛称，登记只会扩大误报面；物料清单因专指 BOM 而保留登记，本词违反第 2 条（非普通工程用词）与第 3 条（不另有所指）。 |
| 支管 | 管路 | 支管是真实存在的管道组成件名称，指从干管分出的分支管，手册中对同一层级使用分支管路的表述，违反第 2 条与第 3 条。 |
| 主线 | 管线 | 手册以主线指称图纸栅格（栅格主线），工程习惯上又以主线指干管主线路，该词已另有所指，违反第 3 条（不另有所指）。 |
| 接管 | 管口 | 接管是真实的管道组成件，指焊接到设备壳体上的短管，手册亦按此义使用，属无法回避的工程用词且另有所指，违反第 2 条与第 3 条。 |
| 接口 | 管口 | 接口是通用词，可指程序调用界面、数据交换通道与界面元素等多种事物，登记它将误伤大量合法行文，违反第 2 条（非普通工程用词）。 |
| 配件 | 管件 | 配件泛指备品备件与附件，与管件这一具体对象类别不在同一层面，且属普通工程用词，违反第 1 条（同一概念）与第 2 条（非普通工程用词）。 |
| 接头 | 管件 | 接头既可用于管路连接件，也可用于电气与机械连接件，并非专指管件的错误叫法，违反第 1 条（同一概念）与第 2 条（非普通工程用词）。 |
| 仪器 | 仪表 | 仪器是实验室与精密测量装置的通用称谓，仪器仪表又是行业惯用搭配，并非仪表的错误叫法，违反第 1 条（同一概念）与第 2 条（非普通工程用词）。 |
| 阀类 | 阀门 | 阀类指阀门这一类对象的集合称谓，而非单个阀门对象的错误叫法，二者不在同一指称层面，违反第 1 条（同一概念）。 |
| 设备对象 | 设备 | 设备对象用于指称设备类对象的实例层级，需求行文中会与仪表对象等表述并列出现，属无法回避的普通用词，违反第 2 条（非普通工程用词）。 |
| 设备接口 | 管口 | 设备接口涵盖一台设备对外暴露的全部交互通道，包括电气通道与数据通道，与管口不是同一对象，违反第 1 条与第 2 条。 |
| 信号电缆 | 信号线 | 信号电缆是采购的实体线缆物料，信号线是图面上的连线对象，二者不是同一事物，且该词在电气语境中另有所指，违反第 1 条与第 3 条。 |
| 控制线 | 信号线 | 控制线在工程中通常指控制回路或控制线路，词义随语境漂移，无法稳定地作为信号线的错误叫法判定，违反第 3 条（不另有所指）。 |
| 模板属性 | 属性模板 | 手册中存在"源模板属性值"的表述，意为某模板条目的属性取值，登记模板属性将误伤这一合法短语，违反第 3 条（不另有所指）。 |
| 属性集模板 | 属性模板 | 属性集模板指"属性集合的模板"，属于另一层组合概念；本规范包并未定义属性集对象，登记后无法机械判定，违反第 1 条（同一概念）。 |

## 使用与维护规则

- 新术语必须先在术语表中登记，然后才允许在任何交付物中首次使用；未经登记的术语不得出现在需求正文、界面文案或代码标识中。
- `禁用别名`列出的叫法不得出现在任何交付物的标题、表格、界面标签或需求正文中。
- 仅在叙述性行文中允许使用如下受认可的简称：`类库`代指类型库、`TAG`代指位号、`BOM`代指材料清单；简称不得取代规范术语出现在标题、表格或界面标签中。
- 英文名是代码标识符、JSON 键名与文件名的用词来源，命名时统一采用英文名的 PascalCase 或 camelCase 形态。
- 对别名列的任何新增或移除，都必须对照`禁用别名判定规则`中的四条标准逐条论证，说明该词满足或不满足每一条标准的依据。
- `已移除与不登记的疑似别名`中列出的词汇不得重新加回别名列；确需恢复登记的，须先以反证推翻相应判定标准条款，而非绕过该标准直接加回。
- 别名扫描覆盖`docs/pid-platform`目录下的全部`.md`交付物，执行命令为`python -m pytest scripts/pid-platform -q -k terminology`。
