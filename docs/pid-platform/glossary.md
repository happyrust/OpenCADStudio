# P&ID 平台术语表

## 唯一词源声明

本术语表是本规范包全部交付物（PRD、架构文档、需求文档、界面原型、校验脚手架）的唯一词源。任何在上述交付物中出现的业务与技术术语，必须先在本表中登记后方可使用；当其他文档与本术语表对同一词汇的表述不一致时，以本术语表为准。`禁用别名`一列具有约束力：其中列出的叫法不得在任何交付物的标题、表格、界面标签或需求正文中出现。

## 术语表

下表登记本规范包的 24 个规范术语，中文名与英文名为正式称谓，定义描述其在本产品中的含义。

| 中文名 | 英文名 | 定义 | 禁用别名 |
| --- | --- | --- | --- |
| 位号 | Tag | P&ID 对象的身份主键，用于把图形、属性、拓扑关系、材料清单与 2D/3D 关联归属到同一个对象，而非仅供图面显示的文字。由项目位号规则生成并接受唯一校验。 | 编号、标签号 |
| 管线 | Pipe Line | 共享同一管线号的一条或多条分支的总称，是工艺介质输送路径的顶层对象，承载管线号、介质、公称直径、管道等级等线级属性。 | 管道线、主线 |
| 管路 | Pipe Run | 管线之下的一条分支，拥有自己的位号后缀与分支级属性，是管线在图面上实际走线与连接的组织单位。 | 支管、子管线 |
| 管段 | Pipe Segment | 管件与管件之间、或管件与管口之间可连接的最小分段，其属性继承自所属管路。 | 线段、管段线 |
| 管件 | Fitting | 接入管路的管道组成件，如法兰、盲板、异径管、过滤器，经连接点吸附在管段之间。 | 配件、接头 |
| 阀门 | Valve | 安装在管路上起通断、调节或保护作用的管件类符号实例，携带位号并参与材料统计。 | 阀体、阀类 |
| 设备 | Equipment | P&ID 中的工艺设备对象（容器、泵、换热器等），通过管口与管路连接，可在属性窗口中做 XY 方向比例缩放，同型实例之间可建立关联共享属性。 | 装备、设备对象 |
| 管口 | Nozzle | 设备上供管路或仪表连接的接口，其位号前缀继承所属设备位号；可由项目设置中的自动管口功能生成。 | 接管、设备接口 |
| 仪表 | Instrument | 测量与控制类符号对象（如变送器、调节类仪表），可加入仪表回路，并经信号线与管口或设备建立关联。 | 仪器、仪表设备 |
| 仪表回路 | Instrument Loop | 一组协同完成同一测控功能的仪表构成的逻辑分组，支持新建回路、添加仪表、移除仪表三种维护操作。 | 控制回路、仪表组 |
| 信号线 | Signal Line | 表示仪表之间、或仪表与设备之间信号传递路径的连线对象，经信号线型连接点挂接，可使用页间连接符跨图延续。 | 信号电缆、控制线 |
| 页间连接符 | Inter-sheet Connector | 管线或信号线跨越两张图纸时的接续符号，携带属性传递与首尾（来去向）信息，把分布在不同图上的同一条线联为同一对象。 | 跨页符、跨页连接符 |
| 打断符 | Break Symbol | 管线交叉处表示视觉断开的标记符号，其样式与高度在项目设置中定义。 | 断开符、跳线 |
| 图例标准 | Symbol Standard | 一套完整命名的符号体系（手册列有 HG/T 20519、SY/T 0003、DIN、ISO），每个项目选定一套，一旦图面产生符号实例即不可切换。 | 图例集、符号标准集 |
| 符号 | Symbol | 图例标准之下可复用的图形定义，含名称、符号类型、颜色、状态与连接点，插入图纸后即成为携带属性的对象实例。 | 图符、图形记号 |
| 连接点 | Connection Point | 符号上用于吸附与建立拓扑连接的锚点，类型分为等径、异径、信号线，方向分为双向点、流入点、流出点。 | 挂点、连接锚点 |
| 类型库 | Type Library | P&ID 管理器下按业务对象组织的类/型树，子类型的类型编码全局唯一且创建后不可修改，类型节点上挂接属性分组与数据要素绑定，是全部对象属性 schema 的来源。 | 业务类库、类型表 |
| 数据要素 | Data Element | 平台层定义的可复用数据单元，绑定数据定义给出的类型与长度，被类型库中的属性分组通过"关联要素"引用。 | 数据项、数据字段 |
| 属性模板 | Attribute Template | 类型节点上预置的属性分组集合，约定关联要素、默认值、可选信息/必选信息级别与拼接规则，对象实例创建时按此落下属性。 | 模板属性、属性集模板 |
| 材料清单 | Bill of Materials (BOM) | 以位号为基准把图面对象实例按类型与属性聚合统计形成的交付清单，覆盖管件、阀门、设备等可统计对象；其模板结构与聚合口径由本规范包自行定义（新增设计）。 | 料表、物料表 |
| 设计规则检查 | Design Rule Check | 对图纸对象执行连通性、属性完整性与规则符合性检查的机制，含规则定义与结果模型；参考产品仅有一句宣称，具体设计由本规范包完成（新增设计）。 | 设计校核、错误校验 |
| 图纸版本快照 | Sheet Version Snapshot | 单张图纸在某一时刻的图形内容与对象数据的整体存档，可生成多个版本并做两两差异比对。 | 版本存档、快照版本 |
| PBS | Plant Breakdown Structure | 项目内组织 P&ID 图纸的层级分解结构（按装置、单元等逐级展开），图纸挂接在 PBS 节点下，权限圈选与发布范围沿其组织。 | WBS、工厂分解树 |
| 项目主数据 | Project Master Data | 项目级共享的取值数据集合，包括公称直径序列、管道等级、绝热等级、流体介质等，绘图时作为对象属性的取值来源。 | 基础数据、主数据表 |

### 使用与维护规则

- 新术语必须先在术语表中登记，然后才允许在任何交付物中首次使用；未经登记的术语不得出现在需求正文、界面文案或代码标识中。
- `禁用别名`列出的叫法不得出现在任何交付物的标题、表格、界面标签或需求正文中。
- 仅在叙述性行文中允许使用如下受认可的简称：`类库`代指类型库、`TAG`代指位号、`BOM`代指材料清单；简称不得取代规范术语出现在标题、表格或界面标签中。
- 英文名是代码标识符、JSON 键名与文件名的用词来源，命名时统一采用英文名的 PascalCase 或 camelCase 形态。
