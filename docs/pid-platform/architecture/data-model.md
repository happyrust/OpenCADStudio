# 领域数据模型

## 领域对象分类

本平台对象按口径分三类。P&ID 专业对象是图纸上的业务实体，携带位号或参与位号体系，是设计规则检查的直接对象。配置对象是定义业务实体语义的模板与规则，决定对象能携带哪些属性、如何编号、显示什么颜色。容器对象是承载与组织数据的结构与边界，包括项目空间、PBS 节点、图纸、图纸版本快照与发布包。

### P&ID 专业对象

| 对象 | 中文 | 关键属性 | 关系 | 唯一性或命名规则 |
| --- | --- | --- | --- | --- |
| Pipe Line | 管线 | 管线号、管道等级、公称直径、绝热等级、流体介质、管线类型 | 1 管线对 n 管路，属性下传给管路 | 管线号由位号规则生成，开启位号唯一校验时全项目唯一 |
| Pipe Run | 管路 | 管路号后缀、继承自管线的属性 | n 管路对 1 管线，1 管路对 n 管段与管件 | 后缀为必选字段且在同一管线内自增 |
| Pipe Segment | 管段 | 前后连接关系、流向、继承自管路的属性 | 连接管件与管件、管件与管口 | 无独立位号，随所属管路 |
| Fitting | 管件 | 法兰、盲板、异径管、过滤器、连接点类型 | 吸附在管段之间 | 参与所属管路的位号体系，不单独编号 |
| Valve | 阀门 | 位号、属性表字段、插入点、连接点 1 与连接点 2 | 插入时管线自动断开，移动时自动补位 | 位号按所属类型的位号规则生成 |
| Equipment | 设备 | 位号、XY 缩放比例、属性表、管口集合 | 1 设备对 n 管口，设备之间可建关联 | 位号按类型规则生成，跨图纸同一设备须建立关联否则被唯一校验拦截 |
| Nozzle | 管口 | 位号、管口类型 | n 管口对 1 设备 | 位号前缀继承设备位号 |
| Logical Connection Point | 逻辑连接点 | 无实体，仅存连接关系 | 未指定默认管口时捕捉设备轮廓自动生成 | 无位号，只能经结构树删除 |
| Instrument | 仪表 | 位号、属性表、所属仪表回路、信号线型连接点 | n 仪表对 n 仪表回路 | 位号按类型规则生成 |
| Instrument Loop | 仪表回路 | 回路编号、成员仪表集合 | 1 回路对 n 仪表 | 回路编号在项目内唯一 |
| Signal Line | 信号线 | 线型、线宽、流向箭头、连接点类型 | 连接仪表，可经页间连接符跨图纸 | 无位号，以两端对象标识 |
| Inter-sheet Connector | 页间连接符 | 目标图纸、流向（流入或流出）、连接的管线或信号线 | 把两张图上的同一条线联为同一对象 | 同一线号在同一张图纸上至多一个流入连接符 |
| Break Symbol | 打断符 | 样式、高度、打断间距 | 落在管线上标记视觉断开 | 项目级样式，无位号 |
| Tag | 位号 | 位号文本、所属类型、唯一校验结果 | 由位号规则生成或被符号标签引用 | 按类型的位号规则，重复时显示「？」待人工修正 |
| Annotation | 标注 | 引用的属性、提示文本、默认值、字体与字高、相对插入点的位置 | 引用被标注对象的属性 | 随标注对象，不单独编号 |

P&ID 专业对象的唯一性以位号为唯一执行口径：凡携带位号的对象，位号在生成时即按所属类型的位号规则校验，重复位号显示「？」并在保存时被阻断；不携带位号的对象随宿主编号，其存在性由宿主拓扑保证，不进入全局唯一校验范围。

### 配置对象

| 对象 | 中文 | 关键属性 | 关系 | 唯一性或命名规则 |
| --- | --- | --- | --- | --- |
| Type | 类型 | 类型编码、名称、层级（父或子）、描述 | 类型树自引用，1 类型对 n 属性分组、1 条位号规则、n 颜色规则 | 类型编码全局唯一且创建后不可修改 |
| Type Attribute | 类型属性 | 要素标签、引用的数据要素、默认值、级别（可选信息或必选信息）、拼接表达式 | n 属性对 1 类型，n 属性对 1 数据要素 | 同一类型内要素标签不得重复 |
| Attribute Group | 属性分组 | 分组名、成员属性清单 | 1 分组对 n 类型属性 | 同一类型内分组名唯一 |
| Data Element | 数据要素 | 名称、数据定义、要素标签、说明、小数位与单位 | n 数据要素对 1 数据定义，被类型属性与符号标签引用 | 名称全局唯一且创建后不可修改 |
| Data Definition | 数据定义 | 名称、数据类型、长度、输入类型 | 1 数据定义对 n 数据要素 | 名称唯一，被引用后不可修改 |
| Symbol Standard | 图例标准 | 标准名称、状态 | 1 标准对 n 符号分类，n 分类对 n 符号 | 名称全局唯一，项目选定后只此一套生效 |
| Symbol Category | 符号分类 | 名称、层级（大中小类） | 分类树，同步为元件库选项板页签 | 同一标准内同级名称唯一 |
| Symbol | 符号 | 名称、符号类型、颜色、状态、线型与线宽、外形、连接点集合、属性标签集合 | n 符号对 1 分类，n 符号与 n 类型多对多 | 名称在同一分类内唯一，被引用后不可改名 |
| Connection Point | 连接点 | 类型（等径或异径或信号线）、方向（双向或流入或流出）、位置 | n 连接点对 1 符号 | 同一符号内编号唯一，被引用后不可修改 |
| Tag Rule | 位号规则 | 名称、格式名称、自动编码、起始编码、增量、后缀递增、拼接字段、位号唯一校验、自动弹窗、状态 | n 规则对 1 类型 | 同一类型同时只有 1 条有效规则 |
| Color Rule | 颜色规则 | 名称、颜色、条件表达式、状态 | n 规则对 1 类型 | 同一类型内规则名唯一，按优先级取首个命中 |
| Nominal Diameter | 公称直径 | 取值、显示标签、外径、隐藏标记 | 项目级枚举，被管线与管件引用 | 取值不可新建或删除，只能隐藏，标签改动只对新建对象生效 |
| Piping Class | 管道等级 | 名称、扩展属性列 | 项目级，绘制时下拉引用 | 名称在项目内唯一，改动只对新建管线生效 |
| Insulation Class | 绝热等级 | 名称、扩展属性列 | 项目级 | 名称在项目内唯一，改动只对新建对象生效 |
| Fluid Medium | 流体介质 | 名称、扩展属性列 | 项目级 | 名称在项目内唯一，改动只对新建对象生效 |

配置对象的唯一性按作用域分级执行：类型编码与数据要素名称全局唯一且创建后不可修改；符号、连接点与规则的名称在各自父容器内唯一，被引用后冻结；项目主数据类对象的名称在项目内唯一，其取值改动只对新建对象生效，存量对象不回溯改写。

### 容器对象

| 对象 | 中文 | 关键属性 | 关系 | 唯一性或命名规则 |
| --- | --- | --- | --- | --- |
| Project Space | 项目空间 | 名称、编号、状态、图例标准选型、成员与角色、项目主数据 | 1 项目空间对 n PBS 节点、n 图纸、n 图纸版本快照 | 名称与编号在平台内唯一 |
| PBS Node | PBS 节点 | 名称、类型（工厂或装置或单元）、父子关系、节点权限 | 1 节点对 n 子节点与 n 图纸 | 同一父节点下同级名称唯一 |
| Sheet | 图纸 | 文件名、所属 PBS 节点、图纸状态、图纸权限、图层与图块 | n 图纸对 1 PBS 节点，1 图纸对 n 符号实例 | 文件名在项目内唯一 |
| Sheet Version Snapshot | 图纸版本快照 | 快照时间、快照内容、生成人、生成原因 | n 快照对 1 图纸 | 同一图纸的快照序号单调递增且不可修改 |
| Publish Package | 发布包 | 包名、图纸清单、报表清单、生成时间、签核状态 | 1 发布包对 n 图纸与 n 报表 | 包名加版本号在项目内唯一 |

容器对象的唯一性沿包容关系逐层判定：项目空间名称与编号在平台内唯一，PBS 节点名称与图纸文件名在各自父容器内唯一，图纸版本快照按序号单调递增且写入后不可修改，发布包以包名加版本号在项目内唯一，全部判定可机械复算。

## 对象关系总览

```text
项目空间
├─ PBS 节点（树状，父子层级）
│   └─ 图纸
│       └─ 符号实例
│           ├─ 设备 ── 1:n ── 管口
│           ├─ 阀门
│           ├─ 管件
│           ├─ 仪表 ── n:n ── 仪表回路
│           ├─ 管线 ── 1:n ── 管路 ── 1:n ── 管段
│           ├─ 信号线
│           ├─ 页间连接符
│           ├─ 打断符
│           └─ 标注
├─ 项目主数据（公称直径、管道等级、绝热等级、流体介质）
├─ 类型树 → 属性分组 → 类型属性 → 数据要素 → 数据定义
└─ 图例标准 → 符号分类 → 符号 → 连接点与属性标签
```

三条不变量贯穿全图：位号是全局连接键，跨图纸拓扑、材料清单聚合、权限占用与审计检索一律以位号为键；图形是数据的外在表现，图形可由数据重建而数据不依赖图形存在；符号与类型多对多解耦，同一符号可映射多个类型，同一类型可选用多个符号。

## 属性传递链

以下五条传递链是本平台对象属性的传播规则，五条全部为强制规则。

| 传递链 | 传递内容 | 生效时机 | 冲突与例外 |
| --- | --- | --- | --- |
| 管线 → 管路 → 管段 | 管级属性（管道等级、公称直径、绝热等级、流体介质、管线类型）先落到管线再下传给管路，管段继承所属管路的当前值 | 管路创建时全量继承，管线改值后按覆盖标记决定是否重写管路 | 管路被手工改过的字段打上覆盖标记，后续管线改值不再覆盖该字段，管段无覆盖标记始终取所属管路当前值 |
| 设备 → 管口（位号前缀继承） | 管口位号前缀取所属设备的位号，设备位号变更时前缀同步更新 | 管口创建时写入，设备位号修改后立即重算 | 管口位号后缀由项目设置维护，重算只改前缀，重算后冲突则显示「？」并阻断保存 |
| 关联设备双向共享 | 两台设备建立关联后共享同一属性集，任一侧修改即时写回另一侧 | 建立关联时合并属性，任一属性提交时双向写入 | 两侧取值不同时以最后提交的一侧为准，并在审计日志中记录两侧原值 |
| 类型 → 子类型规则继承 | 位号规则与颜色规则沿类型树自叶向根上溯，取最近一条有效定义 | 对象创建、类型变更、规则启用或停用时求值 | 子类型定义的规则优先于父类型，父类型新增规则不覆盖子类型已定义的同名规则 |
| 页间连接属性传递 | 页间连接符建立后，管线或信号线的线级属性与首尾流向信息在两张图纸之间传递 | 创建页间连接符时写入，任一侧线属性修改时同步 | 两侧属性冲突时以流入侧为准，并在流出侧标注冲突待确认 |

五条传递链的求值顺序固定：位号前缀继承先于位号唯一校验执行，保证校验看到的是重算后的位号；规则沿类型树的上溯继承先于属性下传执行，保证下传值取的是生效规则解析出的当前值；页间连接属性传递最后执行，保证跨图写入不被同图内的下传覆盖。

## 图例标准唯一性

图例标准在项目内遵守三条规则：

- 一个项目空间在创建时选定**一套**图例标准，且同时只有一套生效
- 一旦项目内产生任何符号实例，图例标准**不可切换**
- 切换被拒绝时返回可判定的错误：错误码 `SYMBOL_STANDARD_LOCKED`，并列出阻断实例数

| 阶段 | 允许操作 | 判定条件 |
| --- | --- | --- |
| 未产生数据实例 | 可切换图例标准 | 项目内符号实例数为 0 |
| 已产生数据实例 | 允许新增该标准下的符号与分类，不允许切换 | 符号实例数 ≥ 1 |
| 已发布项目 | 只允许只读查看与导出 | 存在已签核的发布包 |
