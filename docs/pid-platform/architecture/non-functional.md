## 兼容性

| 兼容项 | 支持范围 | 判定条件 |
| --- | --- | --- |
| 图纸文件格式 | DWG 与 DXF 各 7 个版本（2018、2013、2010、2007、2004、2000、R14），另有 DWT 2018 | 每个版本各 1 个往返用例，保存后位号与属性丢失数为 0 |
| 既有图例规则集 | `assets/pid-legend.json` | 载入后 15 条块规则、6 条圆规则、11 个位号类、50 条形状字典全部可用 |
| 桌面客户端 | Windows 10 与 Windows 11 x64 | 每个系统各 1 次安装与首屏启动，耗时 ≤ 60 秒 |
| 服务端 | Windows Server 2019 及以上，或 Linux x86_64 | 每种操作系统各 1 次启动与健康检查，返回 200 |
| Web 端浏览器 | Chromium 内核 ≥ 120 | 14 屏全部可达且控制台错误数为 0 |
| 字符编码 | UTF-8 与 GB18030 | 中英文混合图纸保存后重开，字符错乱数为 0 |
| 单图纸体积 | ≤ 200 MB | 该体积图纸可打开且保存成功 |

## 信创适配

- 若部署于国产处理器服务器（鲲鹏 920 或飞腾 S2500），则服务端须提供 aarch64 构建产物，并以 1 次启动与健康检查通过为验收条件。
- 若运行于国产操作系统（麒麟 V10 或统信 UOS），则服务端与 Web 端须各提供 1 个适配构建，桌面端以 1 次安装与首屏启动为验收条件。
- 若要求数据库国产化（达梦 DM8 或人大金仓 KingbaseES v8），则数据访问层须提供 SQL 方言适配，并以 1 条方言用例通过为验收条件。
- 若使用国产浏览器（Chromium 内核 ≥ 100），则 14 屏可达性用例须全部通过，控制台错误数为 0。
- 若项目要求国密算法（SM2、SM3、SM4），则登录与会话签名须支持算法开关，并以 1 条切换用例通过为验收条件。
- 若上述条件均不成立（Windows x64 加 x86_64 服务器），则本节不生效，不影响其余各节指标。

以上均为条件式要求，本规格不承诺任何一项已交付。

## 可用性

| 指标 | 目标值 | 判定条件 |
| --- | --- | --- |
| 桌面端脱机可用性 | 100% | 断网后完成绘图、生成位号、保存与出图，失败步骤数为 0 |
| 服务端可用性 | ≥ 99.5% 每月 | 按月统计不可用时长，累计 ≤ 3.6 小时 |
| 故障恢复时间 | ≤ 30 分钟 | 从服务端进程终止到健康检查返回 200 |
| 数据恢复点 | ≤ 15 分钟 | 两次增量备份之间的最大时间间隔 |
| 保存原子性 | 100% | 保存中断用例 10 次，图纸文件损坏数为 0，`.bak` 完整恢复数为 10 |
| 崩溃恢复 | ≤ 5 分钟 | 进程强制结束后重开，未保存变更的丢失量按时间计 ≤ 5 分钟 |

## 可观测性

| 观测信号 | 采集点 | 判定条件 |
| --- | --- | --- |
| 规则检查耗时 | 每次检查结束 | 记录总耗时与对象数，可按项目与时间范围查询 |
| 位号变更审计 | 每次位号新增、修改、删除 | 按位号可查到最近 1 次修改的时间、操作者与新旧值 |
| 同步冲突计数 | 每次脱机到在线同步 | 冲突数与已解决数分别计数，未解决冲突数大于 0 时阻断发布 |
| 自动化调用审计 | `src/mcp.rs` 的每次读操作与执行操作 | 记录操作名、调用者、耗时与结果码，保留 ≥ 365 天 |
| 崩溃与异常 | 客户端进程与出图任务 | 每次崩溃生成 1 份含堆栈的日志文件 |
| 保存校验结果 | 每次保存 | 记录 `save_verified` 的校验和比对结果，失败时记录原因 |
