# 参考产品能力基线 — PIMCenter Designer P&ID V25R4.1

## 模块能力基线

以下九个模块名逐字取自厂商产品简介（2.Designer_P_ID产品简介.txt 第二节），是本规范包的规范性模块词汇。九个模块中仅三个 P&ID 功能簇在手册中有实质正文——P&ID 管理器 §5.1.4.3、P&ID 设置 §6.1.5.1、Designer P&ID §6.2.2——合计约占 260 页正文的四分之一，其余模块依赖平台层对话框或只有零散章节。

### 业务类型库及属性管理

- **能力描述**：为 P&ID 业务对象（管线、设备、阀门、仪表等）建立类/型树并在类型节点上挂接属性分组与数据要素，是全部对象属性 schema 与位号拼接规则的来源。
- **关键对象**：类型节点、属性分组、数据要素、数据定义、动态数据集。
- **实现方式**：B/S 浏览器客户端，类型树在 P&ID 管理器中维护，属 L0–L4 配置分层中靠平台/工作区侧的数据；子类型的类型编码全局唯一、创建后不可修改；类型节点可拖拽换父，删除时级联删除全部后代；属性分组通过"关联要素"引用数据要素，可设默认值与可选信息/必选信息级别，并支持用 `&` 拼接属性、以单引号包裹常量的表达式；平台层另有数据定义（String/Integer 等）、数据要素、动态数据集（值集且要求组合唯一）与记录状态等对话框。
- **手册依据**：§5.1.4.3.1、§5.1.4.3.1.2.2.1、§5.1.4.3.1.2.3、§5.1.4.3.1.2.4、§5.1.5.1、§5.1.5.2、§5.1.5.3

### 标准图例定制

- **能力描述**：定义并维护多套命名图例标准及其下的符号，供项目选用并在绘图调色板中按分类取用。
- **关键对象**：图例标准、符号分类、符号、连接点、符号标签。
- **实现方式**：浏览器端图例库管理；图例标准下挂符号分类树，分类结构同步为绘图面板的页签；符号字段含名称、符号类型、颜色、状态，新建符号默认为"无效"、须置"有效"后方可编辑；符号编辑器提供线、圆、圆弧、椭圆、椭圆弧、填充、修剪等图元并支持从图纸粘贴取材；连接点分等径/异径/信号线三类与双向点/流入点/流出点三向，直通类管件的两个连接点须对称且与插入点共线；属性定义与符号标签支持标记、提示、默认、文字设置与位置；符号更新经图纸刷新传导到既有实例，连接点在"是否被引用=是"后即锁定。
- **手册依据**：§5.1.4.3.2、§5.1.4.3.2.2.2.1、§5.1.4.3.2.2.3.1、§5.1.4.3.2.2.3.2、§5.1.4.3.2.2.3.3、§5.1.4.3.2.2.3.6

### 项目设置

- **能力描述**：项目级 P&ID 设置，绘图开始前由项目侧一次配置，约束全项目图纸的显示、取值与编码行为。
- **关键对象**：项目图例标准、位号规则、颜色规则、公称直径条目、管道等级、绝热等级、流体介质。
- **实现方式**：基础/显示设置含 7 种管线类型 × 3 种流向的交叉打断线宽、两种交叉样式及其打断/间隙宽度、打断符样式与高度、图例标准选择、自动管口；颜色规则按类型树继承并带总开关；位号规则含格式名、自动编码（起始码+增量）、层级选择（当前类型依次递增或父类型递增）、拼接字段来源（当前工程对象/图纸/常数值）、位号唯一校验、自动弹窗与状态；公称直径 DN 表按单位初始化，仅显示标签与外径可编辑且不可增删；管道等级必填"管道等级名称"并可挂扩展属性；绝热等级与流体介质两节近乎空白，仅注明"参照材料等级设置"。
- **手册依据**：§6.1.5.1、§6.1.5.1.1、§6.1.5.1.2、§6.1.5.1.3、§6.1.5.1.4、§6.1.5.1.5、§6.1.5.1.6、§6.1.5.1.7

### 用户设置

- **能力描述**：个人绘图偏好、快捷键与平台级首选项的维护。
- **关键对象**：草图设置、用户环境、快捷键映射、首选项。
- **实现方式**：必须区分两个存储域——草图设置（捕捉/栅格、对象捕捉、默认图层/颜色/单位/样式）随图纸存储，用户环境（配色方案、绘图区元素颜色、十字光标大小、快捷键）随用户存储；另有平台首选项覆盖主题、绘图背景、语言与时区、起始页、邮件订阅与密码。快捷键规则：修饰键加恰好一个主键，修饰键 1–3 个且不重复，Enter/Esc/Tab/Delete 禁用，F1–F12 可单独使用，空格与 Ctrl+右键不可定制。
- **手册依据**：§6.2.2.3.2、§6.2.2.3.3、§6.2.2.3.3.2.1.3、§4.1.2.8

### 图纸权限管理

- **能力描述**：手册仅以一句"对图纸进行权限管理"带过，未给出权限动词、主体模型或继承规则。
- **关键对象**：权限节点、角色、图纸条目、PBS 节点。
- **实现方式**：参考产品真正成体系的权限机制在平台侧——功能权限树按节点挂操作，数据权限分编辑人/查看人/抄送人/附加查看权限，按工作区套用；项目级另有"权限控制"入口。图纸级粒度没有任何文档支撑，本规范包将其定义为新增设计。
- **手册依据**：§6.2.2.1.2.1.6、§5.1.6.3、§5.1.6.4、§6.1.3

### 2D 绘图

- **能力描述**：所有文档类型共用的通用绘图底座，承载图元绘制、图层、图块与注释。
- **关键对象**：图层、图块、注释样式、图片对象、草图设置。
- **实现方式**：功能区含常用/工具/显示/绘图/帮助五类页签；提供图层管理器、图块定义与图块编辑器、注释样式（标注、引线）、IMAGEATTACH 图片插入（jpg/jpeg/png，归图层管理，可调不透明度与比例并控制叠放次序）、绘图设置、视图缩放与线宽。手册自述绘图内核（D2D）与 P&ID 解耦、经接口通信，理论上可被其他图种复用。
- **手册依据**：§6.2.2.3、§6.2.2.3.1.2.1.4.1、§6.2.2.3.1.2.1.4.2、§6.2.2.3.1.2.1.5、§6.2.2.3.4.2.1.12

### PID 绘图

- **能力描述**：P&ID 语义绘图层，把符号实例组织成携带位号与拓扑关系的工艺对象。
- **关键对象**：管线、管路、管段、管件、阀门、设备、管口、仪表、仪表回路、信号线、页间连接符、打断符。
- **实现方式**：新建管线按位号规则自动生成管线号；管路支持分支、连续绘制与层级移动；管件与阀门带捕捉插入，命中管段时自动打断并自动补全管段；空格旋转、Ctrl+空格循环切换插入点/连接点；打断符表达交叉断开；设备在属性窗口中做 XY 比例缩放；管口分自动管口与逻辑连接点两种方式；设备关联使同型实例间属性双向共享；仪表与仪表回路支持新建回路、添加仪表、移除仪表；管线与信号线可用页间连接符跨图，携带属性传递与首尾信息；对象可跨图复制；标注分手动、自动与提示三种。
- **手册依据**：§6.2.2.3.4、§6.2.2.3.4.2.1.1、§6.2.2.3.4.2.1.7、§6.2.2.3.4.2.1.10、§6.2.2.3.5

### 数据管理

- **能力描述**：图纸对象实例与属性的浏览、定位、编辑、批量导入导出及图纸版本管理。
- **关键对象**：对象实例、属性值、位号、版本快照、属性导入导出文件。
- **实现方式**：对象属性管理器左侧列出本图出现的符号类型树，实例列表含子类型实例，右侧呈现全量属性；单击位号在图面上高亮并居中定位，双击进入编辑；支持整图实例导出/导入做批量修改；图纸预览带位号检索；图纸版本快照可生成并做版本比对；撤销能力为 10 步图形级 undo/redo，对象级数据回退在手册中被明确标注"暂未开放"。
- **手册依据**：§6.2.2.3.6、§6.2.2.3.7、§6.2.2.1.2.1.7、§6.2.2.1.2.1.8

### 数据发布

- **能力描述**：图纸与报表向项目外的输出，是参考产品中"发布"一词的全部落地内容。
- **关键对象**：导出任务、报表模板、清单模板、平台文档库。
- **实现方式**：实际只有导出能力——图纸可导出 SVG/DWG/PDF 到本地或平台文档库，范围按目录树圈选；报表导出按模板文件、清单模板、导出格式、范围四个要素执行。手册中没有发布模型、交付包、审批链或 API 契约。
- **手册依据**：§6.2.2.4、§6.2.2.4.1、§6.2.2.4.2

## 无文档支撑的能力

以下能力在手册中被宣传语点名或仅存在章节标题，但正文没有任何落地内容——无数据模型、无界面、无规则定义——因此本规范包对它们的全部规定均为新增设计。

### 设计规则检查引擎

手册证据为 §3.2.1 中一句话宣称产品提供自动设计错误检查，正文再无任何对应章节。缺失项：无数据模型、无界面、无规则定义——既无规则如何表达与挂接的说明，也无检查结果的结构与严重度分级。本规范包将该引擎从零定义并标注新增设计。

### 材料清单生成

手册证据为 §3.2.1 同一句话宣称自动生成材料清单，以及 §6.2.2.4.2 报表导出对话框中的一个"清单模板"下拉框——该下拉没有模板格式说明，也没有任何聚合规则。缺失项：无数据模型、无界面、无规则定义。本规范包从零定义材料清单的模板、口径与生成流程并标注新增设计。

### 协同设计

手册证据为 §6.2.2.2 章仅存在标题、正文为空。缺失项：无数据模型、无界面、无规则定义——多人同时编辑的锁粒度、冲突处理、在线状态均无任何描述。本规范包从零定义协同能力并标注新增设计。

### 对象级数据回退

手册证据为 §6.2.2.3.7 将对象数据回退明确标注"暂未开放"，而图形级撤销仅支持 10 步 undo/redo。缺失项：无数据模型、无界面、无规则定义——回退的对象粒度、触发条件与与快照的关系均无说明。本规范包从零定义该能力并标注新增设计。
