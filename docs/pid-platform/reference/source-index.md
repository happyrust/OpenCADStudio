### 读表规则

- `来源`列只取两种值：以 `§` 前缀的手册章节号，或字面量 `新增设计`。
- `§` 值指向 V25R4.1 用户手册的章节，以分析文件中提取的章节树与正文为准。
- `新增设计` 表示参考产品对该主题没有任何可用文档，相应需求是本规范包的自主决策。
- 本表是各需求文档中 `区域` 列的可追溯锚点：需求条目通过区域代码回指本表，再由本表定位到手册证据或标注为自主设计。
