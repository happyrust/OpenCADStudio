# 交付与发布需求

本文档定义 P&ID 平台的交付与发布需求，共 11 条，按 5 个小节组织。编号规则见 `docs/pid-platform/requirements/00-overview.md`；设计规则检查的结果模型与触发时机在 `docs/pid-platform/requirements/50-data-and-rule-engine.md` 定义，图纸版本快照的生成在 `docs/pid-platform/requirements/40-drawing-and-drafting.md` 定义，本文档不重复定义。

## 材料清单聚合

材料清单按位号聚合，聚合键为位号，满足唯一性不变量：**一个位号在同一份材料清单中至多占一行**。聚合只统计状态为 `有效` 的实例，`已删除` 实例不计入。

材料清单标准表头（原型 BOM 屏的权威列名）：

| 序号 | 类型 | 位号 | 名称 | 数量 | 单位 |
| --- | --- | --- | --- | --- | --- |
| 1 | 管线 | L-1001 | 工艺水进料管线 | 24.5 | m |
| 2 | 设备 | P-1001 | 离心泵 | 1 | 台 |
| 3 | 阀门 | V-1001 | 截止阀 DN50 | 2 | 个 |
| 4 | 仪表 | TI-1001 | 温度变送器 | 1 | 台 |

数量公式两条：管路类材料 `数量 = Σ管段长度`，单位 `m`；设备、阀门、仪表类 `数量 = 实例计数`，单位 `台/个`。

管路类按管段长度累加、四舍五入保留 2 位小数；设备、阀门、仪表按实例个数计数，同一材料的多个实例合并为一行，`数量` 相加、`单位` 取该类型默认单位；管件按实例计数，单位 `个`。

### REQ-DELV-001 材料清单聚合键与唯一性不变量

- **优先级**：必须
- **用户故事**：作为工艺设计人员，我希望材料清单按位号聚合同一材料的多个实例，以便清单行数与工程口径一致。
- **验收标准**：
  1. 聚合键为 `位号`，同一份 `材料清单` 内位号唯一：3 个 `V-1001` 实例聚合为 1 行，`数量` 显示 3。
  2. 同一份清单出现同位号 2 行时写入返回 `BOM_DUPLICATE_TAG`，清单不产出。
  3. 同一图纸内 `已删除` 实例不计入：1 个 `有效` 实例与 1 个 `已删除` 实例聚合后 `数量` 为 1。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 聚合键 | String | 是 | 恒为 `位号` |
  | 状态过滤 | Enum(有效) | 是 | 只统计有效实例 |
  | 行数 | Integer | 是 | 只读 |
- **来源**：新增设计

### REQ-DELV-002 材料数量公式与计量单位

- **优先级**：必须
- **用户故事**：作为工艺设计人员，我希望材料数量按类型分别用长度累加或实例计数得出，以便数量口径正确。
- **验收标准**：
  1. 管路类材料 `数量 = Σ管段长度`，单位 `m`：3 个管段长度分别为 10.005、8.5、6 m 时 `数量` 显示 24.51，按四舍五入保留 2 位小数。
  2. 设备、阀门、仪表类 `数量 = 实例计数`，单位 `台/个`：2 台泵合并为 1 行显示 `数量` 2 `台`，3 个阀门合并为 1 行显示 `数量` 3 `个`，管件同样按实例计数、单位 `个`。
  3. 同一材料的多个实例合并为 1 行，`数量` 相加、`单位` 取该类型默认单位。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 数量 | Number | 是 | 管路类保留 2 位小数 |
  | 单位 | String | 是 | 类型默认单位 |
  | 管段长度合计 | Number | 条件必填 | 管路类 |
  | 实例数 | Integer | 条件必填 | 计数类 |
- **来源**：新增设计

### REQ-DELV-003 聚合范围与版本快照绑定

- **优先级**：必须
- **用户故事**：作为工艺设计人员，我希望材料清单按图纸、PBS 节点或项目三种范围聚合并与图纸版本快照绑定，以便清单版本可回溯。
- **验收标准**：
  1. `聚合范围` 恰为 `图纸`、`PBS 节点`、`项目` 3 选 1；切到 `项目` 级时清单行数等于项目内全部有效实例的聚合行数。
  2. 每份清单绑定 `图纸版本快照`；对已绑定 `图纸版本快照` 的清单发起改写返回 `SNAPSHOT_IMMUTABLE`，仅允许重算出新版本。
  3. `聚合范围` 为 `PBS 节点` 时须选定 1 个节点，未选节点执行聚合返回 `SCOPE_NOT_SELECTED`。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 聚合范围 | Enum(图纸/PBS 节点/项目) | 是 | 恰 3 选 1 |
  | 快照序号 | Integer | 是 | 绑定的图纸版本快照 |
  | 节点 | String | 条件必填 | 范围为 PBS 节点时必填 |
- **来源**：新增设计

## 报表模板

模板由三部分组成：`表头区` 定义清单列名与固定信息，`明细区` 定义逐行字段映射，`汇总区` 定义合计与小计。模板以 JSON 声明，字段映射用 `数据要素` 名称引用类型库字段。模板分 `报表模板` 与 `清单模板` 两类，对应参考产品的两个下拉项；模板可版本化，版本号形如 `1.0.0`；模板变更后既有导出任务使用发布时的模板版本，不跟随模板后续修改。

### REQ-DELV-004 报表模板与字段映射

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望用 JSON 模板声明表头、明细与汇总三区并以数据要素做字段映射，以便清单列结构与类型库一致。
- **验收标准**：
  1. 模板 JSON 的顶层键固定为 `template`、`header`、`detail`、`summary` 4 个，缺任一键返回 `TEMPLATE_SCHEMA_ERROR`。
  2. `detail` 区字段映射按 `数据要素` 名称引用，引用不存在的要素时保存被拒绝并指出该字段名。
  3. 用模板渲染 1 份含 4 行明细的清单：`表头区` 输出 1 次、`明细区` 输出 4 行、`汇总区` 输出 1 次。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 模板内容 | JSON | 是 | 顶层键恰 4 个 |
  | 模板类别 | Enum(报表模板/清单模板) | 是 | 恰 2 值 |
  | 模板版本 | String | 是 | 形如 `1.0.0` |
- **来源**：§6.2.2.4.2

### REQ-DELV-005 模板选择与导出格式

- **优先级**：必须
- **用户故事**：作为工艺设计人员，我希望在导出界面分别选择模板文件与清单模板并选定导出格式，以便输出符合既定模板。
- **验收标准**：
  1. 导出界面保留 `模板文件` 与 `清单模板` 2 个下拉项，`模板文件` 列出可用模板及其 `模板版本`。

  3. 模板由 `1.0.0` 改为 `1.1.0` 后，既有导出任务仍按发布时的 `1.0.0` 渲染。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 模板文件 | String | 是 | 模板下拉项 |
  | 清单模板 | String | 是 | 清单模板下拉项 |
  | 导出格式 | Enum(XLSX/CSV/PDF) | 是 | 恰 3 项 |
  | 模板版本 | String | 是 | 导出时冻结 |
- **来源**：§6.2.2.4.2

## 图纸输出

图纸输出覆盖四种格式，能力与约束各不相同：

| 格式 | 用途 | 输出能力 | 约束 |
| --- | --- | --- | --- |
| DWG | 交付给设计方继续编辑 | 全图元与图层结构 | 按当前图例标准输出，不写位号主数据 |
| DXF | 与第三方 CAD 交换 | 全图元，版本可选 R14 至 2018 | 不保留 P&ID 语义扩展数据 |
| PDF | 归档与审签 | 按图幅与比例输出，矢量文字 | 只读，不含对象属性 |
| SVG | 网页预览与嵌入 | 矢量图形，嵌入字体转路径 | 仅输出当前图纸 |

### REQ-DELV-006 DWG DXF PDF SVG 四格式图纸输出

- **优先级**：必须
- **用户故事**：作为工艺设计人员，我希望同一图纸能输出 DWG、DXF、PDF、SVG 四种格式，以便覆盖编辑、交换、归档与预览四类用途。
- **验收标准**：
  1. 输出格式恰 4 种 `DWG`、`DXF`、`PDF`、`SVG`，每种格式的能力与约束见本节表格。
  2. `DXF` 输出版本可选 `R14` 至 `2018`，选择范围外版本返回 `DXF_VERSION_INVALID`。
  3. `PDF` 产物为只读且不含对象属性，`SVG` 每次仅输出当前图纸 1 张。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 输出格式 | Enum(DWG/DXF/PDF/SVG) | 是 | 恰 4 值 |
  | DXF 版本 | Enum | 条件必填 | R14 至 2018 |
  | 图幅 | String | 是 | — |
  | 比例 | Number | 是 | > 0 |
- **来源**：§6.2.2.4.1

  | 字段 | 类型 | 必填 | 约束 |

  | 导出范围 | Tree | 是 | 复选框树 |

## 数据发布

发布把一组交付物固化为只读基线。发布包由六类内容构成：图纸文件、材料清单、报表、项目主数据快照、校验结果报告、发布清单 JSON。发布对象的状态集恰为 `草稿`、`待审`、`已发布`、`已撤回` 四个值。发布门禁读取 `设计规则检查` 结果，存在错误级结果时发布任务返回 `PUBLISH_BLOCKED`。发布后图纸转只读，修改须走新的修订版本。

### REQ-DELV-008 发布包构成与发布状态

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望发布包内容固定且发布状态受控流转，以便交付物边界清晰。
- **验收标准**：
  1. 发布包恰含 6 类内容：图纸文件、材料清单、报表、项目主数据快照、校验结果报告、发布清单 JSON，缺任一类打包返回 `PACKAGE_INCOMPLETE`。
  2. `发布状态` 恰为 `草稿`、`待审`、`已发布`、`已撤回` 4 值；`已撤回` 转 `待审` 的流转被拒绝并返回 `STATE_FORBIDDEN`。
  3. `已发布` 后图纸变为只读，编辑保存被拒绝，修改须经新建 `修订版本`。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 发布包内容 | List | 是 | 恰 6 类 |
  | 发布状态 | Enum(草稿/待审/已发布/已撤回) | 是 | 恰 4 值 |
  | 修订版本 | Integer | 是 | 发布后递增 |
- **来源**：新增设计

### REQ-DELV-009 发布门禁与校验阻断

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望发布前门禁强制读取校验结果并阻断错误项，以便带错误的图纸不出包。
- **验收标准**：
  1. 发布门禁读取最近一次 `设计规则检查` 结果集，存在 `错误` 级结果时发布任务返回 `PUBLISH_BLOCKED`，发布包不生成。
  2. 仅存在 `警告` 与 `提示` 级结果时发布放行，门禁报告列出全部结果。
  3. 已豁免项不阻断发布，但仍列入门禁报告且 `是否豁免` 显示 `是`。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 错误数 | Integer | 是 | 只读 |
  | 门禁结果 | Enum(放行/PUBLISH_BLOCKED) | 是 | 只读 |
  | 豁免数 | Integer | 是 | 只读 |
- **来源**：新增设计

## 导出矩阵

导出能力按格式区分，矩阵如下：

| 格式 | 导出对象 | 支持程度 | 限制 |
| --- | --- | --- | --- |
| DWG | 图纸 | 完整支持 | 不写位号主数据 |
| DXF | 图纸 | 完整支持 | 不保留语义扩展数据 |
| PDF | 图纸与报表 | 完整支持 | 只读，不含对象属性 |
| SVG | 图纸 | 完整支持 | 仅当前图纸 |
| XLSX | 材料清单、报表、对象属性 | 完整支持 | 列映射由报表模板声明 |
| CSV | 材料清单、对象属性、校验结果 | 完整支持 | UTF-8 编码，不含样式 |
| JSON | 对象属性、校验结果、发布清单 | 完整支持 | 遵循统一导出 schema |

### REQ-DELV-010 导出矩阵的格式能力

- **优先级**：必须
- **用户故事**：作为工艺设计人员，我希望每种导出格式的对象范围、支持程度与限制逐项明确，以便选格式时已知边界。
- **验收标准**：
  1. 导出矩阵恰含 7 种格式：`DWG`、`DXF`、`PDF`、`SVG`、`XLSX`、`CSV`、`JSON`。
  2. 每行 `导出对象`、`支持程度`、`限制` 均非空且可判定，`CSV` 行限制为 `UTF-8 编码，不含样式`。
  3. `XLSX` 导出材料清单时列映射由 `报表模板` 声明，未选模板返回 `TEMPLATE_NOT_SELECTED`。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 格式 | Enum | 是 | 恰 7 值 |
  | 导出对象 | List | 是 | 非空 |
  | 限制 | String | 是 | 非空 |
- **来源**：新增设计

### REQ-DELV-011 导出任务失败重试与结果通知

- **优先级**：必须
- **用户故事**：作为工艺设计人员，我希望导出任务异步执行、失败自动重试并在完成后通知我，以便批量导出不阻塞手头工作。
- **验收标准**：
  1. 导出任务状态恰为 `排队`、`执行中`、`成功`、`失败` 4 值，新建任务初始状态为 `排队`。
  2. 执行失败后自动重试，`重试次数` 上限为 3；重试 3 次仍失败后任务状态置为 `失败`，不再重试。
  3. 任务结束后向发起人发送 1 条通知，内容含 `任务 ID`、`任务状态` 与 `产物链接`。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 任务状态 | Enum(排队/执行中/成功/失败) | 是 | 恰 4 值 |
  | 重试次数 | Integer | 是 | ≤ 3 |
  | 通知人 | String | 是 | 发起人 |
  | 产物链接 | String | 条件必填 | 成功时必填 |
- **来源**：新增设计
