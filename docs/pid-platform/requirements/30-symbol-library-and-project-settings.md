## 图例标准

### REQ-SYM-001 图例标准多套并存与项目选定

- **优先级**：必须
- **用户故事**：作为符号库管理员，我希望系统同时维护多套图例标准并让项目选定其中 1 套，以便同一平台服务遵循不同标准的企业项目。
- **验收标准**：
  1. 系统预置 `HG/T 20519`、`SY/T 0003`、`DIN`、`ISO` 共 4 套图例标准；【新建标准】录入 `标准名称` 后点击【确定】生成空节点，须再以【新建子类】建立大/中/小分类，分类结构直接同步为设计界面「P&ID 符号工具选项板」的选项卡分组。
  2. 标准节点支持新建子类、编辑（改名称）、复制（同级）、删除（连带其下全部分类与符号）、导入、导出；以已存在 `标准名称` 新建返回 `409` 且标准树无新增节点。
  3. 项目在 P&ID 设置的基础设置中经 `图例列表选择` 下拉选定当前标准，下拉列出系统定义的全部图例标准，`自动管口选择` 下拉只列当前图例标准下的管口类型；绘图开始前图例标准可多次修改，图纸内实例数 ≥ 1 时切换标准返回 `FIGURE_STANDARD_LOCKED` 且下拉值不变。
  4. 删除含 12 个符号的标准时确认框显示受影响符号数 12，确认后连带删除其下全部分类与符号。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 标准名称 | String | 是 | ≤ 64 字符，全局唯一 |
  | 标准来源 | String | 否 | — |
  | 符号数 | Integer | 是 | 只读 |
  | 是否当前标准 | Boolean | 是 | 只读 |
  | 状态 | Enum(有效/无效) | 是 | — |
- **来源**：§5.1.4.3.2.2.2.1

## 符号分类

### REQ-SYM-002 符号分类层级与跨标准移动限制

- **优先级**：必须
- **用户故事**：作为符号库管理员，我希望在图例标准下按大/中/小类组织符号分类并可拖拽调整层级与顺序，以便选项板分组与分类树保持一致。
- **验收标准**：
  1. 图例标准节点下经【新建子类】建立符号分类，分类树至少支持 3 层；分类直接同步为「P&ID 符号工具选项板」的选项卡分组，拖拽可改变分类层级与同级顺序。
  2. 拖到其它标准节点下时拒绝并恢复原位置，`父分类` 值不变；同一父节点下 `分类名称` 重名保存返回 `409`。
  3. 分类支持编辑名称、同级复制（副本含其下全部符号）、删除（连带其下全部符号）；删除含 5 个符号的分类后符号网格项数减少 5。
  4. 导入/导出以分类节点为单位；导入 1 个依赖类型库与原符号不一致的符号文件时导入失败，`导入失败列表` 长度为 1。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 分类名称 | String | 是 | ≤ 64 字符，同一父节点下唯一 |
  | 所属标准 | String | 是 | — |
  | 父分类 | String | 否 | — |
  | 符号数 | Integer | 是 | 只读 |
  | 顺序号 | Integer | 是 | — |
- **来源**：§5.1.4.3.2

  | 流向箭头 | Boolean | 条件必填 | 仅 管线/信号线 类型 |

## 连接点

连接点由 `类型` 与 `方向` 2 个维度组合，3 种类型与 3 种方向的全部 9 种组合如下表。

| 类型 | 方向 | 用途 |
| --- | --- | --- |
| 等径 | 双向点 | 等径直通管件两端，介质可双向流动 |
| 等径 | 流入点 | 等径单向流元件入口，介质只能流入 |
| 等径 | 流出点 | 等径单向流元件出口，介质只能流出 |
| 异径 | 双向点 | 异径管两端的变径连接，介质可双向流动 |
| 异径 | 流入点 | 异径单向流元件入口，介质只能流入 |
| 异径 | 流出点 | 异径单向流元件出口，介质只能流出 |
| 信号线 | 双向点 | 仪表之间的双向信号传递 |
| 信号线 | 流入点 | 进入仪表的单向信号 |
| 信号线 | 流出点 | 离开仪表的单向信号 |

- **优先级**：必须
- **用户故事**：作为符号库管理员，我希望为符号放置不同类型与方向的连接点，以便管线与仪表按介质流向正确连接。
- **验收标准**：

  | 方向 | Enum(双向点/流入点/流出点) | 是 | — |
  | 坐标 X | Number | 是 | — |
  | 坐标 Y | Number | 是 | — |

## 位号规则

位号规则的字段定义共 8 项，见下表。

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| 格式名称 | String | 是 | ≤ 64 字符，同一类型内唯一 |
| 起始编码 | Integer | 条件必填 | 自动编码开启时必填，取值 ≥ 0 |
| 增量 | Integer | 条件必填 | 自动编码开启时必填，取值 ≥ 1 |
| 后缀递增 | Boolean | 是 | 管路位号必选；开启后同一位号主体的第 2 个及以后实例追加递增后缀 |
| 层级选择 | Enum(当前类型依次递增/父类型递增) | 条件必填 | 自动编码开启时必填，决定递增计数的来源 |

| 位号唯一校验 | Boolean | 是 | 开启后对同类型位号做唯一性验证，重复时位号显示为 `？` |
| 自动弹窗 | Boolean | 是 | 开启后插入符号立即弹出位号弹窗并强制填写 |

格式拼接示例如下；第 1、2 行为同一规则连续 2 个实例的生成结果，第 3 行为带 `管道等级` 拼接字段的格式。

| 格式名称 | 起始编码 | 增量 | 生成结果 |
| --- | --- | --- | --- |
| `P-{序号}` | 1001 | 1 | `P-1001` |
| `P-{序号}` | 1001 | 1 | `P-1002` |

### REQ-SYM-008 位号自动编码与后缀递增

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望位号按起始编码与增量自动编号并按管路追加递增后缀，以便批量落图时位号连续且不重复。
- **验收标准**：
  1. `自动编码` 开启后按 `起始编码` 与 `增量` 自动生成，起始编码 1001、增量 5 时连续 3 个实例为 `1001`、`1006`、`1011`；关闭时进入手动录入模式，允许输入任意文本。

  4. 管路规则未开启 `后缀递增` 时保存返回 `SUFFIX_REQUIRED`；开启后同一管线第 2 条管路位号为 `P-1001-02`。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |

  | 自动编码 | Boolean | 是 | — |
  | 起始编码 | Integer | 条件必填 | 自动编码开启时必填 |
  | 增量 | Integer | 条件必填 | 自动编码开启时必填 |
  | 层级选择 | Enum(当前类型依次递增/父类型递增) | 条件必填 | 自动编码开启时必填 |
  | 后缀递增 | Boolean | 是 | 管路位号必选 |
- **来源**：§6.1.5.1.3

### REQ-SYM-010 位号规则继承与导入导出

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望未定义规则的类型沿父链套用最近规则并可预览继承来源，以便规则集中在高层级维护。
- **验收标准**：
  1. 当前类型有规则则用之；无则沿父链上溯至最近的父类型规则；父子均无则进入手动录入模式；子类型未定义规则时套用父类型规则且 `继承层级` 显示 1。
  2. 继承结果可预览，显示 `生效来源类型`（类型编码）与 `继承层级`；点击【刷新】后该类型 12 个已存在位号全部重算，失败项以列表返回；新绘制符号默认执行当前有效规则。
  3. 导入 1 条同类型、同名 `格式名称` 的规则时导入失败，`导入失败列表` 长度为 1 且既有规则不变。
- **数据与界面契约**：

## 颜色规则

颜色规则由 `名称`、`颜色`、`描述` 与条件判断 4 部分组成；条件判断按行维护，每行含下表 4 个要素，条件行可增删，多条条件用 `连接符` 连接。

| 条件要素 | 取值 |
| --- | --- |
| 属性 | 当前类型的数据要素名称，下拉选择 |
| 运算符 | `>`、`<`、`=`、`!=`、`>=`、`<=`、`contains`、`!contains` |
| 值 | 手动输入的文本或数字 |
| 连接符 | `or` 或 `and` |

`连接符` 仅当同一规则存在 2 条及以上条件行时生效。

### REQ-SYM-011 颜色规则条件表达式

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望用属性条件表达式定义对象颜色，以便图面颜色随数据取值自动区分。
- **验收标准**：
  1. 新建规则对话框录入 `名称`、`颜色`、`描述`、`条件判断`，`描述` 可为空；条件判断按行维护，每行含 `属性`、`运算符`、`值`、`连接符` 4 个要素。
  2. `运算符` 下拉恰含 `>`、`<`、`=`、`!=`、`>=`、`<=`、`contains`、`!contains` 共 8 个运算符；`连接符` 取 `or` 或 `and`，只在多条件时生效。
  3. `and` 连接时 2 条条件均成立才生效，`or` 连接时任 1 条成立即生效；删除 1 行条件后条件行数减少 1。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 名称 | String | 是 | ≤ 64 字符 |
  | 颜色 | String | 是 | 色值 |
  | 描述 | Text | 否 | — |
  | 属性 | String | 是 | 当前类型数据要素名称 |
  | 运算符 | Enum | 是 | 恰 8 种取值 |
  | 值 | String | 是 | — |
  | 连接符 | Enum(or/and) | 否 | 多条件时必填 |
- **来源**：§6.1.5.1.2

### REQ-SYM-012 颜色规则继承与启用

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望颜色规则沿类型链继承并可经总开关启用或停用，以便分级控制图面着色。
- **验收标准**：
  1. 优先取当前类型的颜色规则；当前类型未定义则沿父链向上取最近 1 条父类规则，父类型有 1 条规则而当前类型无规则时应用父类型颜色且 `继承来源类型` 显示父类型编码；整条链均未定义则执行符号属性中的 `颜色`（默认颜色）。
  2. `启动规则` 为总开关：关闭后所有符号执行符号定义的默认颜色，对象颜色等于符号属性 `颜色` 值；重新开启后所有类型颜色按规则刷新并回到规则色。
  3. 同一类型存在多条规则时按列表自上而下匹配，首个条件成立者生效；导入/导出与位号规则共用同 1 套机制。
- **数据与界面契约**：
  | 字段 | 类型 | 必填 | 约束 |
  | --- | --- | --- | --- |
  | 继承来源类型 | String | 是 | 只读 |
  | 继承层级 | Integer | 是 | 只读 |
  | 启动规则 | Boolean | 是 | 总开关 |
  | 默认颜色 | String | 是 | 只读 |
- **来源**：§6.1.5.1.2

### REQ-SYM-017 相交断线权重

- **优先级**：必须
- **用户故事**：作为项目管理员，我希望按管线类型与方向配置相交断线权重，以便相交管线按规则自动断线。
