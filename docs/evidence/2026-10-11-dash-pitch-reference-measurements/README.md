## 1. 结论（三句）

1. **单一比例成立。** 两族虚线的**周期**（起点到起点，不受端帽影响）都是文件图案的 **1.67 ± 0.03 倍**：` Line2` 3.5/1.75 mm（周期 5.25）在图上周期 8.79 mm；`Electric` 信号线 1.905/1.27 mm（周期 3.175）在图上周期 5.31 mm。两族线宽差 18 倍（0.01 vs 0.18 mm）而比例相同，所以这个比例**不是按线宽缩放**的。
2. **「换成英制图案」排除。** ` Line2` 若画的是 0.25″/0.125″（周期 9.525 mm = 20.2 px），与实测周期 18.6 ± 0.5 px 差 1.5 px/周期、两周期差 3 px，超出 ±1 px；而 `Electric` 本来就是英制 0.075″/0.05″，它同样放大了 1.67 倍——换图案解释不了第二族。
3. **线宽与同一比例相容，但只有 0.70 mm 的线能说话。** 0.70 mm 橄榄主管线 / 立管在图上 1.21–1.30 mm（比例 1.73–1.86，抗锯齿 ±0.3 px 即 ±0.2）；0.35 mm 及更细的线全部落在约 1.2–1.6 px 的栅格下限，说不出倍数。点标记字形也被放大（1.54–1.75 倍，取决于端帽假设），与 1.67 相容。

比例 1.67 的候选解释（本单不定，交 U2 / U3）：5/3；160/96 DPI；某个视图 / 显示比例设置。**周期法给出的 1.675 更贴 5/3（1.667）而非 1.75（175 % 缩放）**：1.75 会让 Line2 周期落到 19.45 px，比实测多 0.85 px/周期。

## 5. 点标记

11 个标记点（蓝 `#0000FF`）的字形长笔 (0,0)→(3,6) mm，名义长 6.708 mm、方向 63.4°。对 9 个干净的字形（去掉与别的墨相邻的两个）把蓝像素换成 mm 后做主轴分析：

| 量 | 值 |
|---|---|
| 主轴方向 | 63–64°（与名义 63.4° 一致 → 等比放大，不是只放大一个轴） |
| 沿主轴总长（含端帽 / 抗锯齿） | 11.49–11.73 mm |
| 垂直主轴宽（含抗锯齿） | 1.21–1.32 mm |
| 若按方帽 / 全减去宽：长 | 10.28–10.48 mm → **s = 1.53–1.56** |
| 若按平帽 / 只减抗锯齿约 0.5 mm：长 | ≈ 11.0–11.2 mm → **s = 1.64–1.67** |
| 不减：上界 | 1.71–1.75 |

点标记**确实被放大**（名义 6.7 mm 的笔画画成 ≥ 10.3 mm），倍数 1.54–1.75，与 1.67 相容；端帽假设决定落在区间哪头。注意：若 SmartPlant 自己的终端符字形不是 3×6 mm 而是另一套单位定义（例如英制），这里的倍数会混进单位差，所以点标记只作旁证。
