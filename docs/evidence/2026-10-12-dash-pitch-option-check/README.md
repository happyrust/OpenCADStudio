# 选项面：纸单位样式尺寸倍数 k=1 与 k=5/3（2026-10-12，t-1615）

V1（`99e6eda4`）把 `PidImportOptions.paper_style_scale` 乘进虚线段长、线宽和点标记，文字不乘，默认 1。这一轮把它接到 settings 和 Options，再用 Vulkan 截图核对。参考图仍是 `D:\work\cad\图片验证\pid-1.png`（U1：` Line2` 周期 8.79 mm，`Electric` 周期 5.31 mm）。OCS 在 k=5/3 时应对上 8.75 / 5.29，而不是去追参考图上多出来的端帽。

**结论**

- **k=1 的 ` Line2` 就是字面节距。** 中间三段划 3.515 / 3.495 / 3.495 mm，空 1.737 / 1.737 / 1.758 / 1.758 mm，中间三个周期都是 **5.253 mm**（文件 3.5+1.75=5.25）。和 `docs/evidence/2026-10-11-line2-fresh-capture/` 的 3.49 / 1.745 是同一档。
- **k=5/3 的 ` Line2` 中间周期 8.759 mm**（期望 8.75，差 **+0.009**，界是 ±0.3）。中间那一划 5.839 mm（5.833），两段空 2.896 / 2.920 mm（2.917）。两端划更长，和 k=1 一样是端帽，不拿来当周期。
- **关掉进程再开，settings 里仍是 5/3，同一窗口的周期还是 8.759 mm**（与上一行逐项相同）。
- **`Electric` 的空段按 5/3 走，周期要躲开气泡接头。** k=1 中间周期 **3.170 mm**（文件 3.175，差 −0.005），空 1.272 mm。k=5/3 只有一个空段，**2.106 mm**（1.27×5/3=2.117，差 −0.011）。两条划都顶到上下气泡，划长 3.920 / 3.941 mm，比图案 3.175 多出约 0.75 mm 的外侧接头；起点到起点因此是 6.027 mm，不用这个数。用空段和文件的划/空比还原周期：2.106×(3.175/1.27) = **5.265 mm**（期望 5.29，差 −0.025）。
- **0.70 mm 主管线的屏幕笔画比是 5/3，世界毫米不是 1.17。** 模型空间线宽是屏幕像素（`MM_TO_PX = 96/25.4`，再 ×2，上限 10 px；见 `src/shaders/wire.wgsl` 的 `MODEL_LINEWEIGHT_BOOST`），不随缩放变成世界毫米。本次取景 58.2 px/mm、截图 `scale_factor` 1.5：k=1 约 8.0 图像像素（反算 0.70 mm），k=5/3 覆盖约 13.3 图像像素（反算 **1.169 mm**，期望 1.17，差 −0.001）。同一取景下的世界宽度是 0.14 mm 与 0.23 mm，比值 1.66。
- **拉丁字高不变。** `LIA`（文件字高 2.469 mm）两次截图的字形墨块行号相同（325..603 与 641..953），高度比 **1.000**。墨块比 2.469 高，是因为窗口里还有相邻文字；比的是 k=5/3 对 k=1，不是对文件字高。
