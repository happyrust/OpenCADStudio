## 3. 怎样算「落入」

周期不受端帽影响。判定窗是 **±0.5 px**。

单段的裸预测不含端帽。任务书的窗是 **±0.5 px 再加端帽 w**（Line2 的 w = 0.826 px，Electric 的 w = 1.618 px）。加端帽的回代是：

```text
划 = s·图案·(px/mm) + w
空 = s·图案·(px/mm) − w
```

这道回代**不是独立样本**。U1 的 w 就是用「划 = 图案·s + w、空 = 图案·s − w」从这同一对划/空解出来的（Line2 解出 s = 1.676，Electric 解出 s = 1.672）。s 改挂到 5/3 上之后残差还在 ±0.2 px 里，只说明 5/3 和当时那个 s 差得不多。Electric 的空在 s = 5/3、w = 0.81 mm 下残差回到 0.000 px，是方程回代，不是新量到的一次吻合。

所以一条机制过不过，看**周期**和 **0.70 mm 线宽**。单段只确认「划偏长、空偏短」的量级像一个端帽，而不是另一套图案。

线宽不再加端帽。0.70 mm 的覆盖率宽比几何宽大约 0.2–0.3 px（U1 §4 已写抗锯齿），残差偏正是预期方向。

## 6. (C) 像素模式仿射

U2 的读者侧（`sub_1007B150`，像素模式开、单位码 11）：中间量 `px = scale·len + offset`，线宽再夹到 `[1, maxPx]`，然后乘 `fView`。屏幕上能拟合的是乘积

```text
段像素 = A·mm + B ，  A = fView·scale ， B = fView·offset
```

一段划、一段空各带一个 B，所以周期（端帽在这里也消掉）：

```text
周期像素 = A·周期 mm + 2B
```

两族周期均值把 A、B 定死，周期残差按构造为 0，**不能**再拿周期给 (C) 报一次「吻合」。留下来检验的是：同一套 A、B 的 0.70 mm 线宽（`max(1, A·0.70+B)`，任务书的 1 px 下限），以及单段残差是否还像一个端帽。

### 6.1 三套坐标的解

| 坐标 | A（px/mm） | B（px） | A×25.4 | 0.70 的预测 | 五条 0.70 |
|---|---:|---:|---:|---:|---|
| PNG 混用 x、y | 3.8627 | −0.832 | 98.11 DPI | 1.872 | **五条都超出**（残差 +0.55 到 +0.88） |
| y 为原始 | 3.3549 | −0.026 | 85.21 DPI | 2.323 | 全部落入（+0.10 到 +0.27） |
| x 为原始 | 3.5562 | −0.027 | 90.33 DPI | 2.462 | 全部落入（+0.10 到 +0.29） |

混用坐标时的解：

```text
A = (18.615 − 10.6) / (5.25 − 3.175) = 8.015 / 2.075 = 3.8627 px/mm
2B = 10.6 − 3.8627 × 3.175 = −1.664 ， B = −0.832 px
0.70 线宽 = 3.8627 × 0.70 − 0.832 = 1.872 px
```

这个 −0.83 px 的偏移把 0.70 的预测从大约 2.7 px 拉到 1.87 px，低于实测下沿 2.42 达 0.55 px。**不改正各向异性时，一套 (A, B) 不能同时吃下两族周期和 0.70 线宽。**

除掉 6% 之后 B 的中心是 −0.03 px。把 Electric 的 ±0.3 px 和 Line2 的两条周期（18.74 与 18.49）四个角都解一遍：y 为原始时 B 扫过 **−0.50 ～ +0.44 px**，x 为原始时 **−0.53 ～ +0.47 px**。0 在这个包络里，−0.83 不在。这张图分得出「一个大偏移」，分不出「b = 0」和「|b| ≤ 0.5 px 的小偏移」。

中心解上，单段加回 §3 的 w 之后残差在 ±0.13 px 内。这仍然是 §3 说的回代：B ≈ 0 且 A ≈ (5/3)·Z 时，(C) 就是 (A)，而 w 是按 (A) 解的。

1 px 下限：中心解的 `A·0.70+B` 是 2.32 或 2.46，都大于 1，**夹不夹，0.70 这一行不变。** 细线才碰下限（y 为原始的中心解）：0.01 mm 裸值 0.008 → 夹到 1（U1 发丝线覆盖率宽 1.21）；0.13 mm 裸值 0.41 → 1（U1 格线 1.38–2.10）；0.18 mm 裸值 0.58 → 1（U1 Electric 宽 1.58，比 1 高 0.58 px）。U1 已把 ≤ 0.35 mm 整档标成栅格下限，高出来的 0.2–1.1 px 是抗锯齿和相邻墨，**不拿细线否决 (C)**。另外 U2 的夹紧发生在乘 `fView` 之前，屏幕上的下限严格说是 `fView×1` 像素，不一定是 1。b ≈ 0 时 A 把 `fView` 和 scale 乘在一起，这张图拆不开 `fView`。0.70 高于下限，这个不确定性不进 0.70 的判定。

(C) 的结论：大偏移（混轴解出的 b = −0.83 px）被 0.70 线宽排除。改正各向异性后 (C) 退化成纯比例，与 (A) 的 5/3、与 (B) 的 85 或 90 DPI 是同一组像素。

因子 1 与五段拉丁的残差在 −0.02 到 −0.40 px，都在 ±0.5 内。因子 5/3 差 3–4 px。因子 0.6 差 1.6–2.4 px。两头都排除。

「说」若按 em 再乘 5/3：19.40 px，比实测 17.46 多 1.94 px，出 ±0.5。U6 §4.2 用 1.67 算得 19.4 px、大约多 2.0 px，是同一笔。按 em、因子 1 则只有 11.64 px，又短 5.8 px——汉字的框本来就不是 em（U6 已写），这里只用来排除「再乘 5/3」。

**0.6 是 `ctx+128`，不是文字的缩放。** 把文字乘 0.6 会被上表直接排除。

三条路径（U5 §6）：

- **(A) 像素模式关。** 虚线因子是 `f0`，文字因子是 `f0×(ctx+128)`。要虚线 = 5/3、文字 = 1，必须 `f0 = 5/3` 且 `ctx+128 = 0.6`（因为 `(5/3)×0.6 = 1`）。用 U1 的中心 1.675 而不是 5/3 时，`ctx+128 = 1/1.675 = 0.597`。用 U6 偏低的 0.92 时大约 0.55。0.6 落在「文字刚好是 1、虚线刚好是 5/3」那个角上，距离 U6 的 ±0.5 px 窗还在里面。文字路径上必须是 **1** 的，是乘积；必须是 **0.6** 的，是 `ctx+128`，而且只在把 `f0` 认成 5/3 的时候。
- **(B) 固定 DPI。** 虚线 / 线宽不走 `f0`。文字路径的因子必须是 **1**。没有任何一项必须是 0.6。
- **(C) 像素模式开。** 虚线不读 `f0`，也不读 `ctx+128`；1.67 在 `fView×(a·len+b)` 里。文字仍是 `f0×(ctx+128)`，这个乘积必须是 **1**。0.6 不是必须的：`f0 = 1、ctx+128 = 1` 与 `f0 = 5/3、ctx+128 = 0.6` 在文字上看起来一样。这张图拆不开这一对。

## 8. 一张图能分开谁；第二张截图量什么

**能分开（这张图已经分开）：** 1.75；DPI 72、96、120；文字被乘 5/3；文字被乘 0.6；以及「不改正各向异性、还要求同一个仿射偏移同时解释 0.70 线宽」。

**分不开：** 5/3 与 160/96。还有「纸面恒定比 5/3」「固定 90 DPI（x 为原始像素）」「固定 85 DPI（y 为原始像素）」「b ≈ 0 的仿射」。当前缩放上 `DPI = (5/3) × Z × 25.4`，Line2 周期 (A) 18.523 px 与 (B) 90 DPI 的 18.602 px 只差 0.08 px。再导一张**同样缩放**的方形像素图，也只是把 85 和 90 分开、告诉你哪一轴被拉过，**仍然分不开 (A) 和 (B)**。

要分开 (A) 和 (B)，缩放得变。周期像素：

```text
(A)  Line2 = 8.750 × Z ，  Electric = 5.2917 × Z
(B90) Line2 = 18.602 ，     Electric = 11.250     （不随 Z 变）
(B85) Line2 = 17.569 ，     Electric = 10.625
```

`|8.750×Z − 18.602| > 2` px 时，±0.5 的窗接不上。即 **Z > 2.355 或 Z < 1.897**（相对现在的 2.117，大约再放大或缩小 11%）。放大到约 2 倍（Z ≈ 4.2）时 (A) 的 Line2 周期约 37 px，(B) 仍是 18.6 px。

建议用户补的那一张，量这些（覆盖率阈值 0.25、分数端点，与 U1 相同；先用 ≥3 个锚点重拟合 kx、ky，若 `|kx/ky − 1| > 2%` 就还是非等比，先改正或重导）：

1. Line2 水平发丝：**两个周期**（划起点到下一划起点）、一段划、一段空。
2. Electric 竖直信号线：**一个周期**，加 U1 那一段两端干净的空。
3. 一条 0.70 mm 橄榄主管的覆盖率线宽。
4. 一个拉丁大写字高（管线号或 LIA）。预期是文件字高 × ky，**不是** 5/3，也**不是**固定 DPI。字高两边（A 与 B）预期相同，不要用它来分 (A)/(B)。

(C) 的 b 若是设备像素里的常数，换缩放后周期像素不动，表现同 (B)；若 b 在纸面上再被视图乘，周期像素跟 Z 走，表现同 (A)。本图中心 `|b| < 0.03` px，第二张图看不出这么小的 b。第二张图的用途就是上表那一列差。

## 9. 各向异性对 (B)(C) 有多大

对 **(A)**：比例在纸面 mm 上算，x、y 各用各的 px/mm，6% 在相除时消掉。两族 s 只差 0.003。各向异性不制造、也不掩盖 (A)。

对 **(B)**：它比的是设备像素。把 x 像素和 y 像素当成同一把尺子，就会多出 5.26 DPI（6.2%），大于 ±0.5 px 换成的 DPI 界，两族看起来互斥。除掉拉宽之后两族差 0.16 DPI。这 6% **就是** (B) 在本图上的全部分歧，不是另有一个比例。

对 **(C)**：同一件混用把偏移解成 B = −0.83 px，并把 0.70 线宽预测拉低 0.55 px 以上，造成「仿射偏移被数据要求」的假象。改正后中心 B = −0.03 px，0 在测量包络里。各向异性对 (C) 的影响是：**能伪造一个出了 ±0.5 px 的偏移；除掉之后偏移不再被这张图要求。**
